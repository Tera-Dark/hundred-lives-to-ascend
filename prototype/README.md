# 《百世劫录》可玩验证切片 · MVP-0

纯浏览器 ES Modules + 独立 `game.mjs` 数值核心，无构建工具、无外部依赖、不连接账号或广告。**这是用来验证玄修与丹修交互手感的临时原型，不是 Cocos Creator 工程，也不是正式 TapTap 小游戏包。**

## 运行

在仓库根目录执行：

```bash
python -m http.server 8000 -d prototype
```

浏览器访问 `http://localhost:8000`。也可以用 VS Code Live Server 打开 `prototype/index.html`。直接 `file://` 双击可能受到 ES Modules 跨源限制。

## 自动测试

```bash
node --test prototype/tests/*.test.mjs
```

纯逻辑模块以后可以按 TypeScript 类型重构后迁移到 Cocos Creator 3.8.8；目前先把「可玩」与「引擎/平台」解耦。

## 验证路径

1. 选择玄修或丹修。使用推进按钮经过本世18/24/34/39年资源与心魔选择。
2. 玄修使用「专注吐纳」「闭关推演」「筑基」，或者丹修采用「普通/省材/驻元护脉丹」。
3. 世界年45预警，60年真实判定；成功继续修炼，失败领取RP并选择传承。
4. 转世后世界历史**不重播**60年的灵潮；世界实体旧玉可找回且保持相同编号。个人事件仍按本世相对年份发生。
5. 进入世界95年地方余波事件，选择稳脉或安全撤离。世界160年作为未制作内容边界，原型安全暂停。

**刻意没有制作**：五流派完整版、完整76种遗物/十级碎片、正式剧情美术、DP/EP、广告、云存档、世界160年第二劫。当前时间推进为手动加速原型体验，不代表正式时长与经济平衡。

## 数据与结构

- `game.mjs`：可复现的单一年份产出/事件状态机、轮回账本、遗物和日志。
- `index.html`：竖屏UI骨架。
- `app.mjs`：按钮事件与 localStorage 本地保存。
- `style.css`：以低饱和墨金色为主的暂定视觉语言。
- `tests/game.test.mjs`：时间事件、防重复、寿限、遗物与轮回流程回归。

存档位于浏览器 localStorage 键 `hundred-lives-prototype-v1`；可在页面底部重置。该版本仅用于本地验证，不具备正式存档迁移承诺。
