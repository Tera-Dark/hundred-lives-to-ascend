# 《百世劫录》法财侣地 × 跨世剧情可玩切片 V1.2

## 本地启动
在仓库根目录运行：

```bash
python -m http.server 8000 -d prototype
```

浏览器访问 `http://localhost:8000/next/`。无需 npm、构建工具、服务端或外部图库。也可从已设置 gh-pages 分支的站点主页进入新试玩。运行自动测试：

```bash
node --test prototype/next/tests/*.test.mjs
```

数据存放在浏览器 `localStorage` 的 `bsjl-v12-current` 键；与旧版 MVP-0 的存档完全隔离。

## 实际实现
- 法财侣地：采药/商行两条职业及 Lv5 晋升、4 种日程计划、3 项研习、灵食与小院维护、浮潮集与青药谷地区切换、顾南枝与沈望川的一次关系抉择。
- 双主修：玄修/丹修，炼气/筑基，三种护脉配方、个人命关与一次性心定印。
- 世界历绝对时间、个人生涯事件、世界 45 预警和 60 灵潮、世界 92/95 地方余波、160 未制作时安全边界。
- 轮回后工作等级和当世货币重置；账号记录职业历史最高等级、RP永久升级、灵藏图谱；同线护心玉唯一ID保留，NPC身份随时间老化，药谷旧约与商路账本留下后果。
- 手机竖屏四入口，剧情弹卡可选、自动本地存档和日志。

## 尚未制作和验收
当前仅实现**两条NPC关系事件的一次性选择和跨世回响**，不是完整的人物支线、多代NPC传记。出身模板、NPC后人互动、长期洞府经营、职业高级两阶、后期剑阵命、遗物Lv10完整强化/七档、世界160危机尚未制作。年份与成本属于可玩体验参数，还需要玩家反馈；不能据此宣称数值已平衡、已有Cocos工程或正式TapTap游戏。

## 建议体验
第一次尝试玄修+商行，前8年营生优先，改善灵食之后切苦修，世界18/34年优先材料，按准备筑基；第二次尝试丹修+采药，改善药物准备、炼护脉丹。帮助顾南枝或沈望川，第一次人生结束轮回后查看「机缘」中的NPC状态与「轮回」中的日志。进入世界95年可看到地方余波事件。
