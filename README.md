# 百世劫录 · Hundred Lives to Ascend

> **一世争长生，万世改天命。**  
> 寿元轮回 × 天地纪元 × 前世遗藏 × 多篇章挑战 × 三阶局外增量。

**当前状态：V0.8 核心乐趣、五主修道途、个人命关与跨世构筑的游戏性设计｜仅策划文档与先前的有限数值模型；无游戏代码/可玩原型/玩家试玩，PRD 未冻结。**

## 游戏是什么？

面向 **TapTap 手机端 Tap 小游戏** 的东方修仙增量游戏。人物先受**寿元**限制，修炼突破可以活得更久；浮岚界的**世界历**在个人轮回后持续向前，纪元杀劫会检验修为、丹药、法宝、势力庇护等多条生存路线。玩家能够封存或遗留真实物品，下一世根据线索找回；轮回点改变下一世的开局和自动化，化神证道与飞升再逐层开启新的奖励和纪元挑战。

**一条主世界观、五个候选纪元篇章：** 灵根初醒 → 万宗争鸣 → 魔潮乱世 → 化神证道 → 飞升天路。更高篇章是同一浮岚界的历史锚点与深层天衡规则，**不是强迫当前长寿人物死掉、也不是每世第100年自动清档**。

**三阶局外永久资源：** ① **轮回点 RP**（普通转世：早期效率/遗泽/自动化）→ ② **道果 DP**（化神证道：法则与流派选择）→ ③ **界源 EP**（飞升及篇章挑战：规则与历史锚点）。低阶资源不可无条件兑换高阶货币。

### 手机上怎样玩？
固定四个主入口：**修行 / 机缘 / 应劫 / 轮回**。新增炼丹、法宝、阵法、宗门支援、证道、篇章选择等都作为对应子功能按进度解锁。主界面持续显示年龄/寿限、当前境界、世界历、下一条杀劫预警、下一目标。重点是少量有价值的取舍，不是层层“点红点升级”。

## 基础原则
- 普通轮回后**同一世界线的历史继续**；选择更高纪元篇章时则建立独立的世界线档案，旧篇章可回访，**实体物品不跨线复制**。魂印、RP/DP/EP、世录属于账号级永久进展。
- “修仙长生”必须是真的：活着突破化神/飞升后，不强制清空这一世；飞升篇章由玩家在安全节点选择进入。
- 纪元斩杀线有提前预告、多条可规划的避劫路线，条件不够确实会死；失败世界仍给下世基本发展途径和照世锚点安全阀。
- 命格、机缘、器魂、前世因果带来惊喜，但正常通关不靠极低概率稀有掉落。
- TapTap **IAA 自愿广告、无内购**；不看广告也能正常延寿、渡劫、获得三阶永久点数。
- **当前只允许策划和文档管理**，未经明确另行授权不创建 Cocos 工程、游戏源代码或真实广告 SDK。

## 版本与开发状态
- V0.1：固定百年末日的早期备选，已淘汰，历史快照 `archive/design-v0.1-before-dual-timeline`。
- V0.2：确立个人寿元优先、世界历继续、历史杀劫及前世真实物件，历史快照 `archive/design-v0.2-before-progression-layers`。
- **V0.3**：加入多篇章、三阶传承与总体系统架构。
- **V0.4**：压缩首版内容与点击负担，建立单世操作密度目标及可复查的纸面试玩。**第一场世界史灾劫只发生一次**；以后轮回看到的是灾后余波/新事件，而非同一世界年60关口重复播放。时间投入、收益与世界事件必须统一结算。时长和操作预算是待测目标，不是已验证事实。
- **V0.5**：第一章经济与事件曝光初试，发现资源策略和新鲜度问题。
- **V0.6**：额外用16种基础策略×3档修为系数进行敏感性测试，并用5组升级×6个预设策略×100种子测试第二世效果。用连续世界线状态模型确认“个人资源事件要按本世进度重新供应、历史大劫同线仅一次、实物唯一”；发现年160的未制作关卡与长寿等待问题。对应测试说明、限制与修订见22/23/24。**模型分析不等于游戏已完成或经济最终平衡**。
- **首段目标时长约7–10分钟，是到第一次世界年60的考验，并不意味着角色必须在10分钟后死去或轮回**；境界寿元允许继续活下去。
- MVP仍只做第一篇章、4–6个RP精选节点、12个事件模板与至少6组条件结果变体、1道完整历史杀劫、1件可寻回实体；化神/道果与飞升/界源是后续扩展。**第二世不能重播同一世界历史节点**。

技术预案为 Cocos Creator 3.8.8 + TypeScript，正式接入前需再次核验 TapTap 运行环境、打包与广告接口。未经用户明确授权，**不开发游戏代码**。

## V0.6 当下设计裁决
- 人物生涯资源事件按本世入世后第18、34年等条件触发，**不能只固定在世界历18、34年**；世界历60年的灵潮仍然只结算一次。
- 世界历160年的下一道关口尚未制作，**原型安全暂停，不判死、不发RP**；计划做正式连续轮回游戏时，至少还需一道复用现有应劫规则的轻量危机。
- 长寿期解锁非付费加速与「推进到下一关键节点」，年龄/世界历/收益必须同步结算，不能靠瞬间快进几百年空刷RP。
- 初世至第60世界年的7–10分钟是**第一体验段**，不代表一世长度。详见 [22](docs/22-PRESTIGE-SEARCH.md)、[23](docs/23-CONTINUOUS-WORLDLINE-TEST.md)、[24](docs/24-LONG-LIFE-PACING.md)。

## V0.7 新增的核心长期收集系统

- **灵藏遗物库**：遗物共鸣图谱属于账号，收录/等级跨世保留；最多携带 **6件**、默认只有 **2槽**，永久用RP与里程碑解锁其余4槽。灵藏槽≠魂印槽≠前世实体遗藏，世界实物不能被灵藏系统复制。
- **七档稀有度**：白30、绿20、蓝12、紫7、黄4、红2、彩1（共76件**长期规划**，不是首版都能获得）。首版目标仅 **8件（白4绿3蓝1）**。
- **重复探索和强化**：普通遗物Lv.1→10；重复获得转专属碎片，升满10级累计花25片；多余碎片按比例兑换同档已有遗物碎片、向上合成通用碎片。**部分独特剧情遗物不可升级**。
- **图鉴/日志/成就**：收录、人生年表、世界线历史、成就目标共用一个首次发奖台账，打开多个界面不重复发RP/碎片。固定四大主入口不变，遗物库放机缘，世录放轮回。
- **数值边界**：遗物类修为产出合计最多+30%，RP加成分层计算，生存替代方案必须付出代价；不可用彩遗物无条件通过所有斩杀线。
- **模拟**：8件首章池、白70%/绿25%/蓝5%、前两件教学保底的2,500种子模型已初审收集及等级速度，见[28](docs/28-RELIC-BALANCE-AUDIT.md)。**未模拟全76件或实际玩家操作**。

**保守MVP：先做2槽、4件验证手感，再扩到8件和完整碎片/图鉴基础闭环；3–6槽、高阶藏品按后续里程碑实现。**

## V0.8 核心玩法新裁决
**一世争长生，万世改天命。** 乐趣不是单纯修为膨胀，而是有限寿元下的机会成本、偶遇机缘改变计划、多个可行过劫方案、前世留下因果与遗物，以及逐渐自动化的重复劳动。

**长期5条主修：玄修（稳定突破）、丹修（有价药性生存）、剑修（高风险抢机缘）、阵修（前置布防）、命修（情报与隐秘捷径）。** 第一版只做**玄修/丹修2条**验证手感；其他依境界/纪元逐步解锁。不是永久职业锁，主修每世可更换；没有5套独立大科技树。权威见[31](docs/31-CULTIVATION-PATHS.md)。

**新补“个人命关”**：每世按修炼进度出现可重复、可变化的心魔/邪祟/灵脉试炼；和世界年60的一次性历史灵潮使用共通求生规则，**绝不重演同一世界历史ID**。权威见[32](docs/32-TRIAL-DIRECTOR-AND-BALANCE.md)。

下一次游戏性验收将使用**2主修×2遗物组合×1个人命关 + 一次世界灵潮**的无美术交互切片；仍需另行授权才能开发。
