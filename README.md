# 百世劫录 · Hundred Lives to Ascend

> **百年一劫，百世问道。** 一款面向 **TapTap 手机小游戏** 的修仙轮回增量游戏：用有限的一百年修行、遇见随机机缘、备战灭世大劫；失败后带走前世所得，一世比一世更接近改写天命。

**当前状态：策划探索 V0.1（Draft）· 仅文档 · 未开始游戏开发。**

## 一句话玩法

每世从不同命格与机缘出发，自动积累修为，围绕“修行 / 机缘 / 备劫”进行少量关键决策；第 100 年迎接“归墟天劫”，结算渡劫成绩并选择遗泽，用轮回点购买改变下一世玩法的永久传承。通过 **纪录、流派、系统解锁、天劫阶段与世界真相** 形成长期目标。

**借鉴方向**：《连续黑白》的人生发展、百年期限、末日验收与轮回积累的高层设计思路；本项目的世界观、角色、能力、数值、事件与美术均须独立创作，**不复制他人的具体内容或资产**。

## 已定的项目原则

- **平台**：TapTap「Tap 小游戏」方向；正式构建与广告规则开发前再次核实。
- **商业**：IAA 纯广告方向，以自愿激励视频为主；无内购、强制广告或广告专属核心突破。
- **技术预案**：Cocos Creator 3.8.8 + TypeScript + Cocos 原生 2D UI；游戏规则与 UI 解耦，增量大数、事件随机、存档与平台接口独立。
- **表现**：9:16 竖屏优先、清雅东方玄幻、界面清晰；战斗与境界突破给予克制但有表现力的动效。
- **玩法**：四个稳定主入口——修行、机缘、备劫、轮回；其余复杂系统按进度嵌套解锁。
- **节奏**：单世游戏内 100 年，游戏时钟不是现实中的 100 年；失败有永久进展，主动游玩有决策价值。
- **开发闸门**：**当前仅允许设定、系统策划和文档讨论**；未经所有者后续明确授权，不创建游戏工程或代码。

## 当前不是正式 PRD

这套文档是便于逐步评审的**第一版设计基线**，不是已经经过玩家测试的玩法或经济结果。世界观和核心约束暂作候选；具体比例、掉落表、100 年耗时、轮回点公式均需模拟和评审。想法未获批准不得自动变成开发范围。

## 协作方式

先讨论 **第一世与前三次轮回是否有趣** → 测试五到十世目标曲线 → 冻结 MVP PRD → 单独授权工程开发 → 原型验证 → TapTap 平台与广告接入。文档细节变更优先修改各自的权威文件，避免多处复制产生冲突。
