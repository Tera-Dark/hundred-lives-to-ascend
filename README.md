# 百世劫录 · Hundred Lives to Ascend

> 一世争长生，万世改天命。

修仙人生经营网页原型：用有限寿元分配营生、修行和研习，积累法财侣地，面对个人命关与持续世界的灾劫，再带着纪录和因果进入下一世。

**当前可玩范围是两世纵向切片，包含墨青留白触控界面、设备体验设置与19项渐进功能指引。** 不是正式Cocos/TapTap发行工程；世界160年后安全暂停。

## 本地运行

需要Node.js 20+与Python 3，无运行时npm依赖，无需 `npm install`。

```powershell
npm run dev
```

- [当前新版](http://127.0.0.1:8000/next/)：保留默认玩家存档。
- [从零体验新手流程](http://127.0.0.1:8000/next/?slot=guide-demo)：独立槽，不覆盖原进度。
- [旧版对照](http://127.0.0.1:8000/)：V1.0旧原型与独立存档。

也可直接运行 `python -m http.server 8000 --bind 127.0.0.1 -d prototype`。ES Modules通过HTTP运行，避免双击HTML。项目目录内入口为 [prototype/next/index.html](prototype/next/index.html)。

## 新手怎么玩

选出身与主修 → 推进1年认识时间与产出 → 逐步开放日程、营生、功法、生活投资 → 炼气后准备筑基或护脉丹 → 探索、立约、应劫 → 轮回追寻旧世界的后果。

- 功能首次开放都有基础介绍，说明用途、成本与下一步；可以收起，标题旁“?”和各功能帮助可随时重看。
- 开放状态跨世保留；旧存档自动迁移，保留原先已有功能，不补弹整套旧介绍。
- 两出身×两主修×两营生可交叉；职业和修仙主修不是同一概念。
- 人物现金/等级重置，账号保留RP/灵藏/纪录，世界历/NPC/地区继续前进；实体旧物不会无限复制。
- 四个玩法入口为修行、机缘、应劫、轮回；底栏第五项为设置。读介绍不耗年、不发资源，不靠广告开放基本生路。

## 手机与体验设置

按钮至少48px，主景使用新生成的留白山水，功能以清晰文字与操作为主。底栏最右侧“设置”提供音乐/音效及独立音量、振动、大字、减少动态、隐藏插画、红点、快进确认与轮回确认。音乐默认关闭，开启后按需播放用户提供的《古琴幽篁》，曲尾交叉淡化，后台暂停。红点表示新介绍或真实条件达标，不是任务要求。首页直接切日程与查看达标机会，支持切页位置记忆、浏览器返回、键盘快捷键、存档导入和替换前恢复。手机单栏、平板/桌面双栏。详情见[体验设置](docs/EXPERIENCE.md)及[本轮验收](docs/QOL-VALIDATION.md)。

## 已知范围

两位NPC只有首次合作和有限跨世回响，完整三幕与后人互动、Lv5后完整经营链、高境界、复杂自动化、76遗物、DP/EP、世界160后内容仍未完成。详见现行待办，历史策划数字不可拼成一套当前经济。

存档默认键仍为 `bsjl-v12-current`，版本2迁移到3，新增损坏备份与导出。GitHub Pages分支保留；公网是否启用、是否已同步本地新版需要独立检查，本地改动不代表已经发布。
