# 百世劫录 · Hundred Lives to Ascend

> **一世争长生，万世改天命。**
>
> 修仙题材 · 寿元驱动 · 纪元危机 · 轮回增量 · 前世寻宝。目标发行：**TapTap 手机端 Tap 小游戏**。

**项目状态：设计草案 V0.2（双时间轴重构）｜仅策划文档，尚未获授权开发游戏代码。**

## 核心玩法

你是一名从凡人修起的修士，首先要在**个人寿元耗尽之前突破境界**，延长这一世的生命；同时，浮岚界的**天地纪元沿世界历持续前进**，在关键年份爆发无法靠普通低阶实力硬扛的灾劫与剧情杀劫。玩家可以凭境界、法宝、阵法或事件准备跨过生存门槛，也可能寿终、战死或主动轮回。

每次轮回都能带走道痕、永久传承和有限的「魂印遗泽」；还可以在持续发展的世界里，沿着**前世留下的线索找到自己埋藏的真正旧物**。世界会记得玩家的某些选择；越多次轮回，越能以新方法突破更高的寿命、纪元与天地限制。

### 两个倒计时，一个世界
- **第一限制：寿元**。年龄在增长，突破与延寿可推迟死亡；不会到第 100 年无条件重置。
- **第二限制：天地纪元**。世界历独立增长，关键年份有提前预告的**生存斩杀线**；未满足至少一类生存条件者会死亡或失去当前世。
- **轮回策略**。寿终 / 灾劫死 / 主动转世均进入结算。可保留跨世资产，但不免费复制所有装备。
- **前世遗物**。魂印随魂带走，实物可藏于洞府、托付势力或遗留墓冢，下世根据线索主动找回；需承担寻找成本和世界变迁风险。
- **防死档**。正常转世默认延续世界历；若世局已不可恢复，可选择照世碑的纪元锚点回溯，但必须遵守世界线和物品唯一性规则。

## 设计原则
- **少入口、深互动**：固定四主入口「修行 / 机缘 / 应劫 / 轮回」，后续炼丹、法宝、阵法、宗门支援按进度嵌入子面板。
- **惊喜来自选择与因果**：不同出身、命格、奇遇、前世遗物与纪元环境产生构筑差异；关键生存路线可规划，不被超低概率卡死。
- **长期目标可见**：突破寿元上限 → 活过首场天劫 → 改变下一纪元 → 寻回重要遗藏 → 解开照世碑之谜。
- **不强迫广告**：IAA 自愿激励广告方向，无内购、无必看视频、无广告才能活命的设计。
- **先规划再开发**：仅在系统耦合、寿元/纪元时间节奏、跨世物品逻辑和前几次轮回乐趣通过评审后才开始做游戏代码。
