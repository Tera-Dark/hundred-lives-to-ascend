# 百世劫录 · Hundred Lives to Ascend

> **一世争长生，万世改天命。**  
> 寿元轮回 × 天地纪元 × 前世遗藏 × 多篇章挑战 × 三阶局外增量。

**当前状态：V0.3 游戏系统骨架草案｜只完成策划文档，没有开始开发代码。**

## 游戏是什么？

面向 **TapTap 手机端 Tap 小游戏** 的东方修仙增量游戏。人物先受**寿元**限制，修炼突破可以活得更久；浮岚界的**世界历**在个人轮回后持续向前，纪元杀劫会检验修为、丹药、法宝、势力庇护等多条生存路线。玩家能够封存或遗留真实物品，下一世根据线索找回；轮回点改变下一世的开局和自动化，化神证道与飞升再逐层开启新的奖励和纪元挑战。

**一条主世界观、五个候选纪元篇章：** 灵根初醒 → 万宗争鸣 → 魔潮乱世 → 化神证道 → 飞升天路。更高篇章是同一浮岚界的历史锚点与深层天衡规则，**不是强迫当前长寿人物死掉、也不是每世第100年自动清档**。

**三阶局外永久资源：** ① **轮回点 RP**（普通转世：早期效率/遗泽/自动化）→ ② **道果 DP**（化神证道：法则与流派选择）→ ③ **界源 EP**（飞升及篇章挑战：规则与历史锚点）。低阶资源不可无条件兑换高阶货币。

### 手机上怎样玩？
固定四个主入口：**修行 / 机缘 / 应劫 / 轮回**。新增炼丹、法宝、阵法、宗门支援、证道、篇章选择等都作为对应子功能按进度解锁。主界面持续显示年龄/寿限、当前境界、世界历、下一条杀劫预警、下一目标。重点是少量有价值的取舍，不是层层“点红点升级”。

## 基础原则
- 普通轮回后**同一世界线的历史继续**；选择更高纪元篇章时则建立独立的世界线档案，旧篇章可回访，**实体物品不跨线复制**。魂印、RP/DP/EP、世录属于账号级永久进展。
- “修仙长生”必须是真的：活着突破化神/飞升后，不强制清空这一世；飞升篇章由玩家在安全节点选择进入。
- 纪元斩杀线有提前预告、多条可规划的避劫路线，条件不够确实会死；失败世界仍给下世基本发展途径和照世锚点安全阀。
- 命格、机缘、器魂、前世因果带来惊喜，但正常通关不靠极低概率稀有掉落。
- TapTap **IAA 自愿广告、无内购**；不看广告也能正常延寿、渡劫、获得三阶永久点数。
- **当前只允许策划和文档管理**，未经明确另行授权不创建 Cocos 工程、游戏源代码或真实广告 SDK。
