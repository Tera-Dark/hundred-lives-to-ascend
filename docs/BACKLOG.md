# 当前边界与后续优先级

这里记录现行缺口。历史评估按原基线保留，不把已经修好的问题继续写成现行缺陷。

## 体验优先

1. 用未读策划的玩家验证指引是否易懂、介绍是否过多、第一次灵潮前能否自主改计划。当前回归与八种指定策略只证明规则可执行，不代表玩家胜率或留存。
2. 完成至少一个NPC的完整两世因果链；目前只有一次合作与有限旧约回响，后人互动及完整三幕尚未制作。
3. 补Lv5后的真实经营成长，以及三项研习全部完成后的时间用途；当前15%及以上研究份额仍可能空转。
4. 补筑基后到世界160的长期目标。160以后安全暂停，高境界、复杂自动委托、DP/EP、五道途完整版和76遗物不在当前范围。

## 已知技术/内容缺口

- `focus`是旧的隐藏动作，尚无界面入口，效果字段没有进入年产计算；不计入可用功能。
- 灵潮幸存额外RP分支依赖不可达的原因字符串，需决定保留还是删除后单独调经济与测试。
- `W02`有定义但没有正常取得路线；当前目录不承诺四件都可收齐。
- 导入、导出和最近一次替换前备份恢复已实现；多槽管理、云存档和跨设备同步尚未制作。
- 精确寿尽年份完成延寿行动的先后次序仍需专门规则裁决与边界测试；不要顺手改经济。
- 真机性能、系统字体、长寿内容密度、百世摘要和正式平台适配尚未验收。

轮回跳过世界60历史、95年与人生资源事件碰撞、已故NPC本人合作、子任务覆盖探索、界面遗物不可卸下、残缺顶层存档导致渲染异常、160导出按钮空操作、迁居目标丢失。相关回归位于 `prototype/next/tests/`。
