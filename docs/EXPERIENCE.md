# 触控、提醒、设置与声音

当前UI以手指点击为基准：所有按钮、开关和折叠标题至少48×48 CSS像素，主要推进按钮52px，底栏五格保留四个玩法页并追加设置。首页直接切日程，列出最多3个达标功能位置；紧凑模式减少重复导航。720px起支持双栏；960px起页面最大宽1100px。修行卡不再用绝对定位挤压操作，文字增长时自然展开。所有数值、按钮和边框仍由HTML/CSS绘制。

## 设置与默认值

| 选项 | 默认 | 行为 |
|---|---|---|
| 背景音乐 | 关 | 按需播放《古琴幽篁》，可重播，曲尾3秒淡化 |
| 操作音效 | 开 | Kenney / CC0本地采样，分点击、成功、事件、突破和失败 |
| 音乐 / 音效音量 | 30% / 45% | 原生滑杆1%调整，独立总线，松手保存 |
| 轻触振动 | 关 | 成功操作短振动，设备不支持时自然忽略 |
| 大字模式 | 关 | 放大正文、说明与按钮文字，不缩小点击区 |
| 减少动态 | 开 | 禁用动画、过渡和平滑滚动；系统减少动态也生效 |
| 显示山水与人物 | 开 | 关闭后隐藏主景和插画，操作与数据完整保留 |
| 可用功能红点 | 开 | 真实达标/未读提示，可完全关闭 |
| 多年快进确认 | 关 | 多年推进前确认；事件与新功能仍会暂停 |
| 跨年行动确认 | 开 | 真实条件满足时先显示年份、灵石/材料/修为消耗 |
| 紧凑首页 | 开 | 缩短主景，首页保留修行/日程/机会/详细安排 |
| 记住浏览位置 | 开 | 按会话记住切页滚动和展开，再点当前页回顶 |
| 操作结果提示 | 开 | 显示实际资源差额，跨世不显示成当世亏损 |
| 键盘快捷键 | 开 | 1–5切页、N推进1年、M音乐；输入和弹层内停用 |
| 主动轮回确认 | 开 | 结束此世前确认；自然离世后进入下世不重复警告 |
| 首次功能介绍 | 开 | 沿用账号`meta.guide.muted`，可收起、恢复、手册重看 |

除首次介绍沿用账号状态，其余偏好保存在 `bsjl-device-preferences-v1`，同一浏览器的试玩槽共用，独立于存档v3。轮回或重开不重置设备设置；恢复体验默认值不改人物进度。导出游戏JSON不包含这些设备偏好。校验只接受白名单字段与正确类型，音量限制在0–100；存储失败显示提示，当前会话设置仍有效。

## 红点规则

`application/notifications.mjs`提供纯查询，浏览器入口负责绘制红点与无障碍说明：

- 新功能已经开放、介绍还未确认。
- `actionStatus()`确认可以突破、推演、探索、寻玉、炼丹或使用心定印。
- 功能已开放且资源够买尚未拥有的灵食/小院。
- 灵藏有空位且有未装备遗物；RP够买尚未解锁的传承；自然离世可进入下世。

底栏与首页入口聚合所属页面的提示，具体操作按钮也标记。普通推进、日程切换、随意迁居、主动轮回不作常驻红点。事件或行动占用期间不提示新的付费行动。红点是“可考虑操作”，不是任务或收益最优建议；材料不足不会亮起丹药提示，已购买/已读/已装备会相应消失。不会用红点去解锁功能、发资源或推进时间。

## 音频与设备适配

`browser/audio.mjs`协调本地CC0采样与用户提供的《古琴幽篁》，来源与处理见[AUDIO](AUDIO.md)。MP3约2.38MB，仅启用音乐后请求，双媒体流在曲尾3秒交叉淡化，不整首解码常驻内存。首次交互启动；背景暂停、返回保留位置，失败可从设置重试。音效继续独立控制与后备。

调整声音只改音频适配层；引擎不读取声音偏好。添加设置需同时更新默认值/校验、页面开关、浏览器实际行为和本页，不能只加入无效开关。真机的扬声器、后台恢复与振动支持仍需分别验收。

## 美术

内置imagegen生成两张新素材：[素材与提示词](../prototype/next/assets/PROMPTS.md)。当前主景为留白远山，静修人物缩小为辅助插画，功能卡和页头采用平色面板。旧六张图片仍保留于素材库作为历史备选，当前视觉由`styles/mobile.css`覆盖。WebP转换只做尺寸与压缩，未手工重绘生成内容。

## 导航、存档与性能

页面hash支持浏览器前进/返回，开放条件仍由应用层检查，不允许深链绕过门槛。浏览位置按槽保存在会话存储，导出不含这部分状态。切页、查看和试听不触发游戏保存；跨年行动和主动轮回有独立确认。弹层阻止背景滚动，取消后恢复触发控件的键盘焦点。

设置支持导入预览与最近一次替换前备份恢复；重开也先备份。导入过大、格式损坏、备份或写入失败时保留原进度。同槽被其他窗口更新时暂停本窗口写入，刷新后再继续。实测与限制见[QOL-VALIDATION](QOL-VALIDATION.md)。
