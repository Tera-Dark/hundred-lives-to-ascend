# 28 · 遗物系统数值/掉落/兑换审计 V0.7（独立实验记录）

> **证据范围**：本轮用临时独立 Python 算术模型进行**掉落/升级的2,500种种子蒙特卡洛检查**、碎片交易图成本检查和修为加成上界计算。**没有Cocos运行测试、真人操作记录、完整多世RP最优策略搜索**；测试模型不代表真实玩家平均刷取时长或商业掉率。经济候选配方的规则权威是 [26](26-RELIC-ECONOMY.md)。

## 二、重复探索模拟：从收集到升级的速度
### 方法（可用文字/脚本重新实现）
- 首篇章普通探索池8件：白W0–W3四件、绿G0–G2三件、蓝B0一件。稀有度权重**70%/25%/5%**，档内**均匀**。
- **另外先给予2份教学保底**：W0一件、G0一件，计为收录Lv1；下表“额外探索次数”**不包括**这两次固定奖励。
- 每次额外探索从以上池取**1件**：未拥有→收录Lv1；已拥有→专属碎片+1；每次遇到满足费用就自动升级（计算简化，不要求正式游戏必须自动升级）；最高Lv10后→同档通用碎片。
- 强化成本从Lv1至Lv10逐级为**1、1、2、2、3、3、4、4、5**，共25片。
- 对每种次数跑 **2,500个独立种子（0–2499）**，只看该数目探索奖励最终的**图鉴覆盖和等级**，不模拟游戏年、灵石或每日登录。探索可以在多世中获得，**不是一世无成本点击一百次**。

| 额外普通探索奖励数 | 已收录不同遗物·中位数 / 8 | 最高遗物等级·中位数 | 达到Lv5及以上遗物数·中位数 | 每种子已到Lv10遗物数·均值 |
|---:|---:|---:|---:|---:|
| **0** | 2 | 1 | 0 | 0 |
| **12** | **6** | **3** | 0 | 0 |
| **24** | **8** | **5** | 1 | 0 |
| **48** | **8** | **6** | 4 | 0 |
| **80** | **8** | **8** | 6 | 0.003 |
| **120** | **8** | **10** | 7 | **0.626** |
| **200** | **8** | **10** | 8 | **3.947** |

**初步判断：** 首两件通过确定性目标获得后，12次探索通常可见6种遗物，24次接近完整早期8种池，同时出现一件约Lv5的角色常用物品；**等级10是真正长线目标**。如果每世只允许2次合法随机探索，那么24次探索就是约12世，80次是约40世（未考虑事件变化/稀有来源）；这仍可能过慢，应由真人试玩/前五世留存决定探索奖励频次和定向渠道，而不是事先承诺合理。

**重要边界**：Lv10白/绿达到满级后可以自动转换溢出碎片；不可升级的隐藏高档从重复池移除，不照此表计算；这8件之外高阶完整76件的碎片经济目前没有模拟结果。

## 三、早期两件修行遗物的增长上界
样品W0「旧纹吐纳玉」Lv1:+3%，每级+0.5个百分点；G0「凝息珠」Lv1:+5%，每级+0.7个百分点。两件全满级之和 **7.5%+11.3%=18.8%**，低于遗物修为产出总上限**+30%**。

将上表随机模拟中的W0/G0等级代入，**只装备这两件**的修为加成中位数：
| 额外探索次数 | 两件修行加成中位数 |
|---:|---:|
| 0 | **+8.0%** |
| 12 | **+9.5%** |
| 24 | **+10.4%** |
| 48 | **+12.1%** |
| 80 | **+13.8%** |
| 120 | **+15.3%** |

效果是**百分比点加法**、不是每级再乘1.05的指数叠加。若同时持有候选一次性RP「旧识经脉」×1.25，且遗物达到群组上限+30%，总修为产出极端上界为**1.25×1.30=1.625倍**。但这仅限制这两个系统的修为维度；没有模拟其它功法、装备/道果的乘法次序，**不代表全游戏数值上界已控制住**。

## 四、碎片兑换不增殖校验
- 任何可重复获得的遗物专属碎片=1单位同档通用；`1专属→1通用`。
- `3同档通用→1已收录目标专属`，再拆回通用只回到1，净损失2。
- `10低档通用→1高档通用`，没有反向兑换；红→彩合成关闭，彩不可升级。
- 单次操作在“稀有度权重价值”下不会创造正收益循环；**但无法单凭经济守恒证明玩家不可以通过时间刷新漏洞无限获得探索奖励**。
- 首次高档解锁只能通过既定的隐藏/挑战条件，不能从普通白碎片直接合成彩遗物。

## 五、与寿元、世界历、斩杀线结合的平衡边界
- 获取遗物本身必须消耗**正常探索行动时间/阶段机会**；不能按无成本连续抽取模型允许玩家第一世刷48次。
- **首场灵潮前不允许单个稀有遗物自动满足全部生存门槛**，第一章稳定筑基/护脉丹路线必须保持独立可行。
- 现有RP修为+25%已被发现能扩大首段可过关的策略组合（[22](22-PRESTIGE-SEARCH.md)）；遗物+8%如果再免费从世界年0开始可能降低首段难度，建议白遗物在**首世世界年24附近**通过首探获得，绿色在**后续历练/首轮后**解锁；需基于统一时间事务重算。
- 6槽不应六件全修行倍率直乘，遵循遗物群组+30%、动作耗时最多减少15%、生存类替代路线仍须投入材料/行动的规则。装备唯一ID不可重复，多余槽位更侧重构筑灵活性和功能搭配。
- 碎片强化是**永久升级**，本世可装备数目仍受2→6槽限制。RP扩槽每次购买后增加组合空间，不应该每世额外扣一次RP。

## 六、已识别的潜在设计问题与整改顺序
| 风险 | 严重度 | 需要的整改/测试 |
|---|---|---|
| 第一章8件池很快见全，后期只剩升级 | 高 | 增加条件事件/因果变体，高级篇章再引入新藏品，不靠无限抽白卡 |
| 需要25个同件重复才能满级，后期稀有升级可能太慢 | 高 | 定向探索/代价明确的兑换，后期可减需求或设目标引导 |
| RP和遗物修炼加成组合使首劫太容易 | 高 | 检查最早获得年份、时间成本、修行计算乘法次序 |
| 六槽全部解锁会让配装成为“把最强六张全塞” | 高 | 不同效用域上限、里程碑/阶段共鸣、互斥效应与多种应劫挑战 |
| 同档与升档兑换耗材无法回收 | 中 | 提供确认/兑换预览，避免新玩家误操作永久浪费 |
| 成就和图鉴重复发碎片/RP | 高 | 账号首达Ledger一次发放，多页面只读同一奖项 |
| 只靠稀有掉落获得隐藏彩 | 高 | 彩档改为确定性可推理隐藏事件/成就，不做低概率刷取 |
| 低稀有度后期全被淘汰 | 中 | 低阶遗物保留采材/预告/探索特殊用途，不能只比纯战力 |
| 不可升级红/彩重复掉落变无限通用币 | 高 | 收录后退出重复池，挑战奖励独立去重 |
