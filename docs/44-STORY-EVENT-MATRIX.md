### 内容生产戒律
1. 同一世界线的历史事件不重复；普通资源事件按本世阶段可以重来但不重复发账号首次成就。
2. 每个重要事件至少改变**年数、资源、风险、可执行方案、人物关系、地区结果、后世后果**之一。
3. 凡NPC剧情选择，不可无成本收获永久资产；拒绝NPC时仍须留一条正常独立的修仙生路。
4. 重要叙事先做“条件→代价→结果→跨世回访”，再追求插画分镜与复杂对话。
5. 现阶段**不添加三十个NPC或数百个随机奇遇**；优先验证两个人是否能让玩家对本世和下一世产生情感与策略牵挂。
