# 24 · V0.6 长寿期节奏、时间加速与RP反空刷

> 长生必须成为真实奖励，但不要求玩家为了“活得久”干等几十分钟。**所有时间和RP设计是待原型验证的候选方案**，不等于已通过真人体验测试。

## 一、原始匀速模型会造成的等待
V0.5暂定7.5秒现实时间=1个游戏年。从**16岁活到当前境界总寿限**，如果没有加速：

| 总寿限 | 要经历的游戏年 | 仅时间推进（不含选择/动画） | 采用8倍速且不含额外操作时 |
| ---: | ---: | ---: | ---: |
| 120 | 104 | **13分钟** | 1.63分钟 |
| 240 | 224 | **28分钟** | 3.5分钟 |
| 500 | 484 | **60.5分钟** | 7.56分钟 |
| 1000 | 984 | **123分钟** | 15.38分钟 |

需要多少内容才能填补？如果坚持不加速、且每90秒要有一次有效反馈，单是年龄16→240就需要至少19个反馈，16→1000需要约82个。首版12个事件模板显然不够。

## 二、推荐的「修行到下一节点」节奏
- 新手首次接触世界与寿元时，适度实时推进，保留成长期待与几次有趣的主动选择。
- 玩家理解时钟并有基础RP传承后，提供 **×2 / ×4 / ×8 的可切换加速**；在「闭关、修炼已熟练功法、无重要事件」段开放 **推进到下一可决策节点**（智能快进），不是任意免费增加修为。
- **智能快进精确消耗所跨越的每一个游戏年**：角色年龄和世界历同步增长，修为/灵石的年产出结算一次；不能跳过个人寿尽、世界历史斩杀线、当世必选机缘、未处理的突破或关键信息。
- 对同一个已完成成就的低阶突破可自动确认；新境界首次突破、法则选择、前世旧物去向仍须提示并暂停。
- 只有无意义重复过程才能批量执行；**主动选择的策略分歧**应该是游戏内容，不应被加速按钮吞掉。
- 不依赖广告解锁倍速与智能快进。不要为了广告人为制造等候时间。

## 三、内容密度从“每多少年出现一次”改为“每段有多少价值”
一段体验由以下节点构成：
1. **准备节点**：当前最高优先级的一项可操作目标，例如缺3灵材、下次突破还需300修为；
2. **成长节点**：达成一项境界/功法/法宝纪录，产生明确的效率或能力反馈；
3. **奇遇节点**：按玩家流派/因果出现互斥选择，不强制每隔10年弹窗；
4. **危险节点**：可预告的寿尽、个人修行试炼或真实世界历史斩杀线；
5. **跨世节点**：角色死亡、主动转世、恢复已知遗藏或下一次历史档案查看。

**规划目标**：一次玩家主动游玩段（约4–8分钟）至少看到2次显著成长/发现反馈、1次有意义决策与一个可继续追求的下一目标；不是“每世必须4–8分钟”，也不是承诺实时每60秒弹框。用可控加速和目标追踪弥补世界事件间的空窗。

## 四、防止“长生只要快进几百年就刷RP”的漏洞
V0.5轮回点公式直接奖励活跃游戏年份；一旦提供×8和智能快进，100–300年的**纯等待可能以很少实际操作获得十几至几十RP**，随后主动转世。这会让挂机快进成为最优解，与玩家希望的“反复玩有乐趣”相反。

**V0.6替代奖励公式的设计候选**：

- `RP_普通 = 成长层深度分 + 实质选择分 + 有效历练年数分(最多2) + 首次世界/寿龄纪录奖励`；不再按裸生存年份无限给点。
- 凡达到RP重复结算条件的一世，需有**至少25年有效修行**及**至少2次可审计的有代价决策**；达不到则重复RP为0，但已经产生的账号首次里程碑可单独在结算时发奖。注意“点击垃圾按钮”不能冒充有效决策。
- 成长分候选：炼气2、筑基5、金丹9；若未进入某境界就不能靠时间获得该档分数。
- 历练分候选：`min(2, floor(有效历练年数 / 35))`；选择分候选：`min(2, floor(max(0, 实质选择次数-2) / 2))`。世界历推进和挂机待机本身不自动制造“有效历练选择”。
- 账号首次：炼气+1、发现并保全首件遗物+1、筑基+2、初次幸存灵潮+3，已领取标记永久去重；**不得把故意死亡当作首达奖励来源**。

### 同一提案公式的样例结果（不含其他目标奖励）
| 一生/决策样例 | 本次RP | 意义 |
| --- | ---: | --- |
| 初世炼气、四项决策、60年灵潮失败、首次发现护心玉 | **6** | 首次失败能买一个3RP升级，和V0.5期待一致 |
| 初世炼气、同条件护脉丹幸存、随后主动转世 | **9** | 生存有额外首达奖励，但**不必**此时转世 |
| 初世筑基、同条件首次幸存后主动转世 | **14** | 长期路线在可计算奖励上有优势 |
| 重复25年、全程没有实质选择 | **0** | 不能轻松刷裸年份 |
| 重复25年、做过2个实质选择、炼气 | **2** | 短轮回可以有少量收益，但不压制深度路线 |
| 重复60年、4个实质选择、炼气 | **4** | 长世有更多奖励与下一阶段机会 |
| 重复120年、4个实质选择、筑基 | **8** | 更深境界与时间投入更值得 |
| 只按“智能快进”活300年、无实质选择 | **0** | 阻断最明显的RP空刷 |

**此公式未被真实玩家行为验证**；是否能通过重复2个低成本选择套利、自动化怎样记录有效决策、长期DP/EP时代是否过度依赖RP，仍需进一步模拟。上表是计划要进行比较的数值下限，不应直接锁定经济。

## 五、智能快进的安全停点
- 停在**最早**发生的：本世新境界突破/行动完成、寿尽、世界历史预告或灾劫、前世遗物回收抉择、未见过的随机事件、玩家设定的主动停止年份、已制作内容边界。
- 一次快进若跨过**两条历史边界**，只能推进到第一条并等待处理；未花完的跳年请求可取消或恢复，不能重复生成资源。
- 遇到世界160尚未实现的内容，**安全暂停，维持当前生命、背包与RP预测**，不自动死、也不发结算奖励。
- UI清楚预览将消耗多少寿元/世界年，以及是否临近危险；不允许利用暂停浏览无限产生修为。
- 不应把离线后台挂机作为无寿元的额外生产渠道；MVP仍禁用“免费离线修为”，之后如新增必须同期模拟寿元与世界年。

## 六、我们目前实际证明和未证明的部分
- **算术上已证明的等待问题**：7.5秒/年导致240年寿限的角色从16岁起空等约28分钟，乘8倍速会降为约3.5分钟（不含操作）。
- **简单经济样例已证明**：候选RP函数在零实质决策的300年快进上给0RP，第一段失败仍可得6RP；这只是公式边界检查。
- **未证明**：智能快进上线后玩家会不会“快进→做两个无聊选择→轮回”刷RP，长寿期机缘质量、实际UI节奏及充值/广告安全。需要可玩原型与更多行为策略模拟。
