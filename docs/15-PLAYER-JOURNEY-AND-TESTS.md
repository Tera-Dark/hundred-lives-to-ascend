# 15 · 前五世体验、长期阶段目标与验收 V0.4

> 以下是**供后续原型与试玩校准的策划剧情/玩法假设**，不是已写好的脚本或正式数值。用于证明“成长层解锁是质变”，以及成长难度随篇章改变但手机入口不变。篇章/局外规则参考 [12](12-ERA-STAGES.md)、[13](13-PRESTIGE-LAYERS.md)。

## 一、第一世至第五世：必须有的五种感受
| 世数示例 | 玩家直觉目标 | 玩点和可获得的成果 | 下一世新变化 |
|---|---|---|---|
| **第1世** | 从普通人活过预估寿限；看到灵潮预警 | 修炼与突破延寿；选择护脉丹或宗门庇护；可能失败 | 首次获得 RP，理解死亡是成长结算 |
| **第2世** | 比上次更快突破，并找回自己留下的东西 | 轮回点投资、第一处已知遗藏、遇见有记忆的碑灵 | 实体前世护心玉确实帮忙渡劫 |
| **第3世** | 面对已经发生的灵潮**余波**或下一处世界关口 | 根据历史后果选择炼丹/修为/庇护，继续增长世界历 | 世界史不可重播；在残存历史上寻求新目标 |
| **第4世** | 达成比过去更高的寿龄/境界纪录 | 命格两选一、初级功法倾向、遗物连携 | 解锁减少低级闭关劳动的永久传承 |
| **第5世** | 第一次真正改变世界事件的结果 | 不只是活命；保护某个地区，获得新历史标记 | 预告后续篇章与证道目标 |

注意：**不能强制玩家第1世必输、第5世必须达成某境界**。这是目标体验序列，实际解锁由里程碑触发；高水平玩家可更快，弱水平玩家通过 RP 与有保障的路线也能逐步达成。

## 二、中长期玩法的五个目标梯度
| 梯度 | 近期目标 | 中期能力质变 | 下一挑战 |
|---|---|---|---|
| 凡俗入门 | 第一境界、第一笔RP、找回上世护心玉 | 自动初阶修炼和明确寿元策略 | 第一历史杀劫 |
| 宗门与结丹 | 初次越过大劫、形成丹/器不同流派 | 事件/装备连携、留藏策略 | 万宗/魔潮难关 |
| 元婴化神 | 通过高阶纪元杀劫，选择证道方向 | **道果**与法则构筑槽 | 化神问心挑战 |
| 飞升破界 | 第一次飞升、开启高阶历史锚点 | **界源**与篇章规则/挑战选择 | 归墟与天衡考验 |
| 诸天问道 | 问道纪录、历史重演挑战、挑战词缀组合 | 自动化低层，优化不同极端构筑 | 逐层上升的规则难度与剧情揭露 |

## 三、完整样例：同一斩杀线的三条生路
**灵潮逆涌**：下面是**不同初始路线的反事实对照**，不是同一世界线第二世重打灵潮。玩家首次遇到此历史事件时提前15个世界年收到预警。
- A **命修**：专心突破，延长寿元同时获得稳定灵气承载；缺点是省下的材料少，可能错过稀有机缘。
- B **丹修**：花费3年学习并炼制护灵丹，以保护经脉通过检查；付出灵材，牺牲一部分境界速度。
- C **宗门**：提前完成听潮观的两项帮助，兑换入阵庇护；功法进展较慢，但留下势力因果，有利后世。
稀有护心玉可能提供第四条捷径，但不应是唯一可用的解决方案。

过关后世界历继续；下次转世见到的不是重播灵潮，而是灵潮遗迹、宗门扩张/损毁等后果。如果玩家进了新的篇章世界线，才从那个篇章所定义的历史锚点展开另一条发展路线。

## 四、轮回与层级重置的体验验证
1. 每次轮回都展示 **现在领取多少 RP、还能怎样争取更高纪录、哪件实物已留在世界里**。
2. 初次道果必须明显改变**下次挑战的新功能**，如额外法则槽/新修行模板，而不只是攻防 +20%。
3. 首次界源必须解锁**新的篇章锚点或挑战规则**，玩家不会觉得飞升后还在打同一只怪。
4. 玩家留在低篇章时依然可以找遗物、解锁局部纪录，但不能无限刷RP后直接等价兑换全部EP。
5. 三阶货币产生与消耗均使用确定性 ID，不能靠重开同一试炼重复领首次奖励。

## V0.4 体验验收参考
- **单世目标**：首世约7–10分钟，普通后续世约4–8分钟；6–9次意义明确的选择，不包含纯导航点击。目标见 [17](17-SESSION-PACING.md)，并非实际试玩数据。
- **跨世逻辑**：世界年60若已发生灵潮，第二世只出现余波与前世遗藏；手工演算与边界问题见 [18](18-PAPER-PLAYTEST.md)。
- **内容密度**：每世约2–4个重大选择事件，10–12个模板按标签复用，同屏最多一主目标、两个辅助行动；切掉无差别领取按钮。
- **预算缩减**：原“每栏2–3 RP节点，共8–12节点”在MVP中压到**总计4–6个精选RP节点**；额外节点只保留在长期目录。

## 五、首个可玩切片（MVP）严格边界
- **只做篇章 I「灵根初醒」**，有1场完整斩杀线与一场后续危机预告。
- 个人寿元/世界历，修行及突破，轻量机缘，基础应劫，轮回RP与一件前世可寻回实物。
- 2条生存路线、2条可区分的功法倾向，4个境界以内，约**10–12个事件模板**（含引导/历史余波；每世只抽2–4个重大选择事件）。
- 1页四栏 RP 传承，但**MVP总共只做4–6个有功能区别的节点**，后续高阶节点锁定预告；**不真正实现 DP/EP 逻辑和高阶世界线切换**。
- 当前篇章第一个小结局后可以继续测试基本成长；但**尚未制作的第二道世界历史斩杀线不可自动判死或空跑**，应明确当前原型的试玩边界。不能声称首版就拥有完整飞升长线世界。

## 六、正式发展中的内容分期
| 阶段 | 内容范围 | 验收重点 |
|---|---|---|
| **MVP** | 第一篇章、普通轮回、实物寻回、基础斩杀线 | 一世可玩、前五世有差异 |
| **扩展 A** | 第二/三篇章、法宝与阵法、世界历史因果 | 多流派确实影响事件成败 |
| **扩展 B** | 化神/证道、道果层、证道试炼 | 新规则层不等于永久倍率 |
| **扩展 C** | 飞升/高阶篇章、界源层、世界线槽 | 跨篇章物品唯一性、成长节奏 |
| **后续** | 组合挑战规则、更多流派和历史结局 | 复玩不只是敌人HP越来越大 |

## 七、模拟和验收矩阵（开发前方案、开发后自动运行）
| 测试 | 风险 | 合格证据 |
|---|---|---|
| 3种不同寿元成长路线 | 某方案绝对最优 | 资源、年份与死亡原因对比 |
| 5世不同随机种子 | 运气决定是否有资格活 | 至少2条保底生存路线 |
| 50–100世标准模拟 | RP刷取、后期秒杀 | 有效成长/短刷收益分布合理 |
| 多层货币连续重置 | 积分重复领/不可恢复死档 | 确切余额/幂等发奖 |
| 化神不结算直接长寿 | 升级被强制清零 | 允许继续当前人生/历史 |
| 留存世界线→切篇章→回访 | 旧遗物跨线复制/档案丢失 | 旧世界继续、跨线无实体穿越 |
| 一次跳过多个世界节点 | 无预警秒杀/事件遗漏 | 每个节点触发一次、可确认 |
| 旧档升级到新版本 | 状态字段丢失 | 可迁移或给出安全恢复方案 |
| 不看广告的连续游玩 | 商业化扭曲平衡 | 核心通关、RP/DP/EP 均可获得 |

## 八、后续需要用户确认的四项高影响决策
1. **篇章 IV/V** 是“化神证道/飞升天路”作为同一世界的规则深层，还是外在地理意义上的天界地图？目前建议前者。
2. **章节切换** 仅在安全节点，保留上一篇章可返回世界线；这样最少伤害前世因果，但存档复杂度更高。
3. **DP/EP** 首次获取是“自动里程碑奖励”还是“主动证道/破界后结算”？建议“挑战达标解锁、确认后领取”，不要强迫现世清零。
4. **初版规模** 强制控制在第一篇章和第一阶RP，第二/第三阶只设计并预留逻辑；高阶内容后续分阶段生产。
