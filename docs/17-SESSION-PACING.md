# 17 · 单世实际体验与操作密度 V0.4（纸面试玩标准）

> **这是策划阶段的可测试节奏目标，不是已完成真实玩家测试。** 目的：低频但有效的选择，持续可见的修为增长、突破、机缘与生存压力；避免一局只有挂机、同时也避免一局点击几十个面板。世界时钟权威见 [10](10-TIME-EPOCH.md)，阶段/奖励见 [12](12-ERA-STAGES.md)、[13](13-PRESTIGE-LAYERS.md)。

## 1. 核心体验问题与裁决

| 发现的问题 | V0.4 裁决 | 为什么 |
| --- | --- | --- |
| “自动时间 + 行动耗年”可能重复消耗寿元 | **统一世界年结算流水线**：正常自动推进和主动行动跳年使用同一推进接口，不双重计时 | 玩家能预测代价 |
| 第 60 年天劫会在第二、第三世重复吗？ | **不会**：同世界线的历史节点仅触发一次，后续变为“余波/遗迹/势力后果”新事件 | 前世历史真实持续 |
| 每世是否要操作四个系统全部升级？ | **不需要**。主页给最重要的1个目标，次级最多2个；成功过关可以只偏好其中一条路 | 操作精简 |
| 事件抽到坏运气就不能活？ | 基础生存至少2条计划内可达路线，稀有事件只提供捷径/流派差异 | 乐趣来自应对不是赌脸 |
| 越长寿会不会越长局越无聊？ | 低阶段自动化、可调倍速和“推进到下一可决策节点”，不能越过危险和首次剧情 | 长寿让策略空间变大而非等更多秒 |
| 后期三阶点数打开过多按钮 | RP/DP/EP逐级显示，MVP只开放RP极浅层；首批只做真正改变操作的节点 | 限制学习成本 |

## 2. 玩法单位与目标频率

**统一单位：游戏内年份。** 默认游戏处于可暂停的自动推进状态；每个真实时间间隔推进一些游戏年，同时产出该时段的修为与资源。玩家选“闭关3年/访友2年”等行动，相当于在一次事务中**推进3/2年并结算期间产出**，不会在已经自动过去的相同年份上再额外扣一次。不可逆卡片展示时游戏内时间暂停。

- **首世真实时长目标**：约 7–10 分钟。优秀玩家可更快完成或继续挑战；原型可选速度，不能设计成现实限时惩罚。
- **熟练后的常规短世**：约 4–8 分钟，取决于主动早退、加速和自动化；长寿冲纪录可以显著更长，但应允许快捷推进已解决的区间。
- **基础时钟原型参数**：约每真实 7–9 秒推进 1 个游戏年（需测试、仅示例），重要行动可主动跳过若干游戏年；第一次事件前必须有足够可操作窗口。
- **一次普通轮回的有效抉择目标**：首世 **6–9 次**，后续世 **5–8 次**。一次抉择是有代价或互斥结果的选择，不包含查看提示、打开面板、按“下一页”。
- **一个重要反馈的间隔**：新手约每 40–75 秒出现突破、事件、装备变化或明确的目标推进；连续无决策且无新反馈尽量不超过 60–90 秒。
- **重大事件数**：通常每世 2–4 个有两种以上选项的主动事件；外加 1–2 个无需选择的发现/境界反馈。是否恰逢历史大劫由世界历决定，**不能为了凑事件数强行重播**。
- **常驻待处理项**：主目标 1 个 + 次要选项不超过 2 个；同一时刻最多 1 张需要立即回复的机缘卡。
- **主要界面点击**：常见动作不超过 2 次点击可执行（如炼制护脉丹、查看备劫缺口）；已见过的低级操作通过 RP 自动化。

这些都是**可测上限和体验目标**，不是规范性行业均值或已经验证的数据。

## 3. 第一世：按体验分钟拆分（非线性、含分支）

| 实际时间参考 | 玩家看到的东西 | 必须发生的体验 | 用户做的主要事 |
| --- | --- | --- | --- |
| 0:00–0:40 | 凡人、年龄/寿限、修为增长、清晰的“冲炼气”目标 | 理解修为会自己增长，不能纯点点点 | 点击一次功法倾向/基础修炼策略 |
| 0:40–1:50 | 首次突破，寿限由80例示提高到120 | **第一次强反馈：修行真的延寿** | 决定冲修为或用灵材研究护身路线 |
| 1:50–3:30 | 一次带风险/收益的机缘、看到灵材与灵石 | 认识“风险、收益、年份成本”的选择 | 机缘二选一；观察代价 |
| 3:30–5:00 | 旧纹护心玉/宗门线索、初次世界事件预警 | **第二个爽点：我获得了能改变生路的东西** | 用/留护心玉、选应劫方向 |
| 5:00–7:30 | 世界历进入第一道灾劫的准备窗口 | 生存门槛可读，至少两条不靠稀有卡的生路 | 选择护灵丹 or 宗门庇护（可选冲筑基） |
| 7:30–10:00 | 世界历触及一次性历史关口或角色寿限/主动轮回 | **第三个爽点：生存/失败的原因明确 + RP第一次买新功能** | 确认生存结果/轮回奖励/遗藏 |

此表为**首世应追求的戏剧性节奏**；玩家提前死、越阶、提速、主动继续长寿时均走状态驱动规则，而不是锁死在某个第几分钟放剧本。

## 4. 常规后来一世：不重新讲教程
开局 10–20 秒内让玩家确认命格和已有继承；自动整理已精通境界与基础资源。根据当前世界历刷新**当世有效目标**：
- 距下一真实历史杀劫很近：应劫路线优先；
- 上一世有已知遗藏：提示寻宝与寿元成本；
- 历史关口已发生：进入**余波事件池**，如战后修复、灵潮废墟、势力迁移；
- 下一道世界关口很远：把境界、寿限、区域机缘/个人修炼考验当作主目标，不制造空等。

## 5. 内容密度的具体预算（MVP）
| 维度 | 推荐预算 | 约束 |
| --- | --- | --- |
| 主导航 | 固定 4 个 | 修行/机缘/应劫/轮回，不另开炼丹/宗门专页 |
| 本世资源 | 修为、灵石、灵材，共 3 种；另有年份约束 | 不再加炼丹点/宗门货币/秘境票 |
| 生命与历史状态 | 年龄/寿限、世界年/下一关口，共 2组 | 必须在主页直接可见 |
| **完整历史斩杀线** | **1 场（灵潮逆涌）** | 一条世界线只发生一次；触发后有后果 |
| 生存路线 | 2条保底 + 可选第3路线 | 不依赖稀有掉落，三种都使用既有资源 |
| 事件模板 | **10–12个（目标）** | 其中2引导、4常规、2机缘联动、2余波、0–2稀有；每世选2–4个活跃 |
| 命格/功法 | 3种命格倾向、2种实质有差异的基础构筑 | 不必新增一棵“命格科技树” |
| 前世遗藏 | 1件剧情保底+1个留藏位置 | 留存/寻回同一uniqueItemId；省掉真实寻路 |
| RP升级 | **首版仅 4–6个精选节点**，尽管完整目录有30候选 | 每笔投入明显改变下世体验；DP/EP锁定预告 |
| NPC/势力 | **1个功能性势力（听潮观）+碑灵** | 故事角色主要通过事件卡呈现 |
| 视觉 | 1张主场景/角色、几套状态反馈、1场危机动画 | 用UI深度代替开地图制作 |

## 6. 核心复杂度预算
- **玩家可见预算**：四个主入口，初期同屏最多一张主行动卡和两张次级卡；绝不在首页呈现四种生产线与30个传承节点。
- **决策预算**：每次大决策最多三种明确比较的选项（年份、灵材、收益/风险写清楚），无意义可自动。
- **数据预算**：角色基本成长和3资源使用共享数值池；制丹/法宝/宗门功能尽量是共享资源驱动的状态修正，不是独立小游戏。
- **开发预算**：先做 1 历史关口 + 10–12 事件模板 + 4–6 RP节点 + 1 遗物闭环；所有 DP/EP、跨篇章、真实 AI NPC 生命周期都不在 MVP。
- **减法规则**：若新增按钮只增加领取动作却不改变资源/年份/风险/存活方式，删除它或加入自动化。

## 7. 需要在纸面测试中追问的三个问题
1. 不点开“应劫”子页，玩家能否在主页看明白下一关该怎么过？
2. 第二世不再重播灵潮，**余波/遗物/新寿龄目标**是否足以提供一世独立目标？
3. 当事件提示很少时，玩家是否出现超过1分钟的纯盯进度条时间？若出现，优先改善自动推进/目标，而不是无脑增加随机弹窗。
