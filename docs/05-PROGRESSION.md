# 05 · 成长层级、解锁节奏与数值策略

> 以下是 **待评审范围和测试假设**，并非最终的经济表。先冻结体验曲线，再根据离线模拟校准公式。

## 1. 三层成长
| 层级 | 周期 | 核心输出 |
|---|---|---|
| 本世 | 1–100 年 | 修为、境界、法宝、备劫储备、奇遇结果 |
| 跨世 | 轮回无限次 | RP 传承、前世遗泽、命格候选、自动化、纪录 |
| 跨世界 | 首次抵御整场灾劫后 | 新阶段目标、规则变体、特殊资源与道统（后续） |

境界数值增长是纵轴，流派选择与灾劫阶段是横轴，轮回点带来永久优化。不要把所有机制推成一棵有百级前置的科技树。

## 2. 功能逐步解锁（轮回次数仅作参考）
| 进度 | 新系统 | 解锁方式候选 |
|---|---|---|
| 初世 1–25 年 | 自动修炼、筑基目标、机缘简选 | 开场教学、境界进度 |
| 初世 50–100 年 | 天劫预告、投入备劫、首场大劫 | 世界年份推进 |
| 首次轮回 | RP 与传承栏目、1 个遗泽槽 | 完成有效本世结算 |
| 2–3 世 | 可选命格、简化重复突破、丹道一条浅路线 | RP 里程碑 + 首次达成筑基 |
| 4–6 世 | 1–2 件法宝、功法路线差异、更多事件 | 境界纪录/灾劫阶段 |
| 7–10 世 | 基础阵法/宗门支援（完整版本候选） | 备劫纪录 + 轮回里程碑 |
| 首次击退归墟投影 | 下个世界层级 | 挑战成功，无需广告 |

**不应要求空刷 10 世才能玩到有趣东西**。玩家首世就必须有“修行/机缘/备劫”选择；第二世的差异在结算后即可理解，复杂度渐进是为了清晰而不是人为拖慢。

## 3. 境界设计：首版可控制为四档
炼气 → 筑基 → 金丹 → 元婴（MVP 可根据进度进一步减少）；每一档具备一个**行为质变**而不仅是更大倍率，如：
- 筑基：首次可主动选择功法倾向。
- 金丹：可稳定承载一件主动遗物/本命法宝。
- 元婴：允许一次有限的特殊规则抵抗。
更高境界（化神、炼虚、合体、飞升）属长期路线，数值范围尚未确定。世界层级与境界层级不是一回事。

## 4. 增量数值系统原则
- 修为是持续生产型数值；基础灵石/灵材是受时间预算限制的决策资源。
- 避免单一路线永远指数领先；同档价格、产出、突破需求按几个阶段的目标时间校准。
- 使用大数表示层封装修为、倍率与比较；**游戏年份、货币开支和抽取 RNG 不强制全用大数**。如果实现超大规模取对数，要考虑精准显示与溢出行为。
- 显示 1.25万、3.4亿、1.2e18 可切换；不让百分号和科学计数法掩盖下一目标。
- 年份/行动成本必须有上限可解释；不允许离线收益把本世悄悄推进到大劫战败。
- 平衡程序以固定随机种子模拟成千上万次轮回，检测边界条件：短轮回刷点、传奇运气、低配置玩家、不同遗泽、离线恢复和溢出。

## 5. 第一版 MVP 的真实目标
- 1 张世界背景、1 种三阶段天劫、4 个境界以内。
- 6–10 个可触发事件、3–4 个命格、2 条有效的功法倾向。
- 轮回点四方向的浅层升级、1 个遗泽槽、数个跨世成就。
- 为第 1–5 世专门调校解锁节奏；至少一个事件/遗泽能明显改写下一世。
- 离线/存档基础机制，能重复游玩且没有数值死锁。
以上不是开发命令，具体数量需在正式 PRD 冻结时根据测试成本批准。

## 6. 需实测的敏感变量
| 变量 | 风险 | 验证方式 |
|---|---|---|
| 单世真实游玩耗时 | 太短无策略，太长乏味 | 记录主动操作和空等时间 |
| RP 收益曲线 | 短刷最优或长玩不值 | 不同轮回长度蒙特卡洛对照 |
| 罕见机缘出现率 | 运气决定胜负 | 控制种子对照、保底稳定路线 |
| 永久倍率 | 几世后秒杀天劫 | 连续 50/100 世自动模拟 |
| 自动化比例 | 玩家后期只看数字 | 主动决策次数/每世变化统计 |
| 大劫难度 | 第 1 世必输或后续纯碾压 | 按流派检查每阶段可通过策略 |
