# 30 · 《百世劫录》核心游戏性定义 V0.8（策划裁决提案）

> 本文回答 **“玩家反复回来到底为了玩什么？”**，优先级高于继续加资源、按钮、收藏数量和新职业。数值仍待可玩原型验证。流派执行定义见 [31](31-CULTIVATION-PATHS.md)，挑战引擎与内容预算见 [32](32-TRIAL-DIRECTOR-AND-BALANCE.md)。

## 1. 一句设计支柱
**在有限寿元与不可倒流的世界历史中，把机缘和遗泽组合成一次独有的修行方案，试着突破这辈子的极限；即使失败，下一世也能用上一世的成果找到不同的生路。**

不把产品定位成“谁挂机倍率最高”，不做传统职业战斗RPG，也不把游戏设计成某条唯一攻略路线的填空题。

### 四个不可替代的乐趣来源
| 支柱 | 玩家的情绪 | 真正的可玩决策 | 不能被哪种伪玩法取代 |
|---|---|---|---|
| **倒计时与取舍** | 我还有几十年，够不够？ | 冲境界 / 炼丹 / 蓄阵 / 冒险 / 避祸 | 等进度条到100% |
| **可改变的命运** | 我发现不一样的活法 | 事件分支、流派与遗物联动，临场调整策略 | 全流派只是+20%收益 |
| **可见的轮回质变** | 曾经拼命，今世轻松越过 | RP/遗物/日志提升决策空间、自动略去已精通旧劳动 | 每世重复点同样十次升级 |
| **世界记住前世** | 上次留下的痕迹这次还在 | 原实体寻回、历史余波、其他人/地区因果变化 | 每100年强制全部世界归零 |

**惊喜的位置**：随机机缘能改变“这世的最佳解”，但基础生存必须有可规划的稳定路。隐藏遗物不是等0.01%随机命中，而是可追踪的线索、条件与意外联动。

## 2. 核心循环分三层
**局内30–90秒反馈：** 修为/寿命预测变化、事件选项、探索材料或遗物碎片 → 立即看懂“我离下个目标更近还是更远”。

**一次4–8分钟主动操作段：** 选当世主修→确定一个可追求目标→根据最近灾劫/命关/机缘调整行动→成功/失败/获得遗物→得到新的下一个目标。允许角色继续长寿，4–8分钟不是强制轮回长度。

**跨世数次到跨纪元：** 有意义的人生结算RP/世录/遗物与魂印 → 低阶已知流程逐步自动化 → 新主修/挑战规则/篇章开放 → 玩家尝试不同且可行的解决方案。

**设计禁令：** 不让同样的世界年60灵潮在世界年62的第二世重演；个人重复挑战与世界历史只能同一个“机制库”，不能共享同一“一次性事件ID”。

## 3. 主修与其他系统的定位
| 系统 | 玩家决策角色 | 切忌 |
|---|---|---|
| **主修道途** | “这辈子打算用什么方法变强/解决危险” | 全部是单调倍率 |
| **灵藏遗物2–6槽** | “为了这个目标，要舍弃哪一种便利，装备哪两件” | 全选收益最大6件，不做选择 |
| **命格** | “出生带来的可利用机会/限制” | 罕见神命格是唯一生存资格 |
| **机缘事件** | “计划外出现一个值得改变原方案的选择” | 持续刷随机箱和低质量弹窗 |
| **个人命关** | “这一世的阶段性可重复挑战” | 在世界年60后完全没可挑战目标 |
| **历史杀劫** | “世界在向前，这一条世界线的历史不可重播” | 为增加复玩重复全球末日 |
| **RP/DP/EP** | “逐渐减少重复劳动、解锁新规则” | 靠快进与廉价两选项刷永久币 |
| **图鉴/日志/成就** | “记住自己为何赢、为何死、如何改变世界” | 三页重复领奖/无用红点 |

## 4. 每一世最小有效体验（验收门槛，不锁死剧情）
1. **一个可见的短期目标**（突破、寻回物品、活过一场个人命关、完成高阶挑战），目标可不同。
2. **至少一次有代价的资源/寿元选择**：放弃别的有价值选项。
3. **至少一次计划的修正机会**：危险预警、机缘或世界后果改变当前最优方案，不能总让玩家按脚本照抄。
4. **至少一次状态的明确变更**：新境界、真正有用的遗物、一个改变历史/后世选项的因果、一次新挑战成绩。
5. **明确的下一目标**：现在转世、继续长寿冲境、换流派追图鉴/隐藏事件，三者至少两条合理可选。
不强制每世都获得新传说遗物、不强制每世打一场全球历史大劫。

## 5. 玩家可说出口的故事比升级数量重要
- “上世炼丹苟过灵潮，这一世带着遗物改修剑道，第一次打过了守关异祟。”
- “我一直堆修为，结果第160年出生太晚，改用阵法和听潮观的旧人情守住了自己。”
- “命修查出了荒谷真正入口，原本被我当作废品的观风铃变成了关键装备。”
- “我没重开世界；旧观真的迁走了，可藏在井边的玉仍然能通过别的线索找到。”

## 6. 从成熟增量游戏提炼而不是照抄
- [Realm Grinder 的派系与后期混搭](https://realm-grinder.fandom.com/wiki/Factions)：不同打法的身份明确，高阶才开放组合；**我们只选5条主修，不照搬数十棵技能树**。
- [Magic Research 2 的法术/自动化与隐藏故事线](https://store.steampowered.com/app/2864890/)：自动化把注意力释放给新机制，发现隐藏剧情本身是成长；**我们不复制数百法术和装备制作规模**。
- [The Gnorp Apologue 的产出/收集与协同](https://gnorp.dev/)：同一增长目标可通过不同工具组合达成；**我们以生命预算与天劫规则取代巨型生产建筑链**。
- 玩家社区的共识倾向于**有意义但都可行的构筑选择**、避免必须抄唯一攻略才能过墙；参考 [讨论A](https://www.reddit.com/r/incremental_games/comments/1i3kqox) / [讨论B](https://www.reddit.com/r/incremental_games/comments/1vjemkw/do_you_prefer_skill_trees_with_meaningful_choices/)；讨论不是普遍用户统计证明。

## 7. “好玩”的定量验收不是单看收益率
| 指标候选 | 判定失败的例子 |
|---|---|
| 关键选择数量/价值 | 一世10次点击，10次都必选收益最大选项 |
| 不同路线有效性 | 修行倍率+25%让其他主修在任何测试环境都没有理由玩 |
| 中途转向价值 | 无论拿到什么遗物/机缘，最佳操作脚本都一模一样 |
| 失败可解释与恢复 | 死亡后不知道缺什么；新生者因世界历太晚必死 |
| 自动化满意度 | 玩家明明有永久升级还必须每世点10次老按钮 |
| 内容复玩 | 第3世以后只有同文案同结果，同一个历史事件回放 |
| 游戏时长与制作复杂度 | 为增加一次真选择引入三套新币种、独立小游戏和几百张图 |

**V0.8 是核心设计假设而非已证实的乐趣。** 下一步必须制作“二主修×二遗物配置×一次个人命关”的**无美术交互切片**，让真实操作数据否定或支持本主张；未经授权不得开始工程开发。
