# 新手指引与渐进开放

当前规则源为 `prototype/next/content/features.mjs`。每项功能有稳定ID、开放条件、两段基础介绍、取舍提示和目标页面/区块。功能按进度发现，阅读介绍不消耗游戏年，也不发奖励。

## 玩家流程

开局先选出身和主修，只开放基础修炼与时间推进。底部四入口保持位置，未开放入口显示锁定状态。每发现新功能出现一张非强制介绍卡：可“去看看”“明白了”或收起首次提示。

普通快进逐年检查开放条件，首次发现时停止，便于玩家注意变化。收起提示后可以继续正常快进，门槛仍然有效。闭关/探索等已付费行动仍按真实年份与剧情停点执行，新手介绍不会打断或覆盖剧情选择。

标题旁“?”随时打开手册，每个已开放面板也有帮助按钮。手册可提前读未开放功能的说明，但不能通过阅读提前操作。重看只重置已读状态，不重置世界、不再发奖、不收回功能。

## 旧玩家与轮回

开放与阅读记录在账号层跨世保留。版本2老存档迁移时，不重新锁掉以前已有的操作界面，也不集中补弹所有旧教程。尚未发现的心魔、RP、自动化、后世与地方余波等继续按真实进度介绍。想重新阅读可在手册选择“重看已开放介绍”。

## 如何增加或调整功能

1. 在 `content/features.mjs` 添加稳定ID、条件、介绍、目标和提示。按年份开放的条件引用命名年份表；改门槛也要改面向玩家的条件文字及本表。
2. 在 `application/commands.mjs` 为操作建立 `requiredFeature` 对应关系；不要只隐藏按钮。
3. 页面用 `featureBlock()`或 `isUnlocked()`控制实际控件。`data-feature`目标必须与功能目录的 `section`一致。
4. 引擎动作继续用 `actionStatus()`/`begin()`，不在指引代码里修改资源或推进时间。
5. 加测试证明：开放前不能执行/扣款，开放后可操作，读档与轮回不丢状态；浏览器检查“去看看”能定位真实功能。

## 文案规则

一项介绍只回答：做什么、消耗/收益是什么、当前可以尝试什么。允许拒绝合作、维持免费生活、收起提示；不要强迫玩家按唯一攻略完成任务。不把完整NPC三幕、76遗物、金丹、道果或世界160后内容写成当前已开放能力。
