# 09 · 策划冻结与开发路线 V0.2

**当前状态：V0.2 设计重构完成初版文档，未冻结 PRD，未获游戏代码开发授权。** 本文件列未来工作，不能据此自动开始工程。

## 已确认的四条核心方向
1. **个人寿元为第一限制**：寿终/遇险时可轮回；突破与延寿能够推迟死亡。
2. **天地纪元为第二限制**：世界历持续向前，关键年份出现致命事件/剧情事件；生存条件不足可能在该世死亡。
3. **前世物件可寻回**：既有魂印传承，也有同一世界线实际遗留的物品与线索。
4. **进度与轮回渐进解锁**：四主入口不变，轮回点提供永久质变，后期系统根据成长/历史纪录逐步出现。

世界观样例、60/160/320/640 年份、寿元数值、获得率、具体 UI 和解锁表尚是**策划提案**，未经过模拟或玩家试玩。

## 下一轮待正式评审的重大问题
| 议题 | 为什么重要 | 需要验证 |
|---|---|---|
| 寿元推进速度 | 过慢会挂机无聊，过快则几分钟老死 | 前三世完整操作录像/原型模拟 |
| 纪元斩杀线间隔 | 世界历持续累积，可能出现后期过快或无事可做 | 模拟多世死亡、长寿修士跨关口 |
| 生存门槛 | 玩家希望“未达标必死”，但不能只靠抽到超稀有资源 | 至少两条不依赖抽卡的可行避劫路径 |
| 失败世界可恢复 | 历史累积危险可能导致下一世出生即死 | 安全区、过渡时间与纪元锚点验证 |
| 前世物品公平性 | 全带走无决策，只能随机找回又挫败 | 一个确保能找回的教学事件 + 唯一性规则 |
| 回溯与世界因果 | 回溯可能抹掉玩家珍惜的物品与故事 | 玩家可预见损失、永久记录与世界线分离 |
| 轮回点收益 | 寿龄/新阶段奖励可能诱导故意送死刷点 | 短/长轮回比较与重复成就去重 |

## 正式 MVP 候选（不是开发任务指令）
- 角色寿元与境界突破延寿；个人/世界两条时间显示。
- 第一条纪元斩杀线，有提前预警、两种正常避劫路线、明确失败与成功。
- 第一世结束、RP 结算、一次魂印选择、默认承世转生。
- **一件前世实物、一次主动留藏/死亡遗留、一次下一世找回**。
- 最基本的世界状态持续与安全恢复；锚点回溯在原型中先验证规则，可视化复杂版本可后置。
- 先 3–5 世可玩，后续再扩展更高纪元和宗门等内容。

## 策划验收清单
- [ ] 写出同一初始条件下“冲突破长寿 / 准备抵御危机”的真实机会成本。
- [ ] 至少两种流派可通过首条斩杀线，无广告/RNG 必需。
- [ ] 个人寿元与世界年份分离，超长寿角色仍能继续游玩。
- [ ] 寿尽/灾劫死/主动轮回都有可解释的收益和后续恢复方式。
- [ ] 第 2 世找回的护心玉是同一件真实物品，非新生成同款奖励。
- [ ] 回溯世界线不会复制遗物或再次刷首次天劫/寿龄 RP。
- [ ] 世界遭受失败后正常转世仍有发展路线；锚点作为最后保险。
- [ ] UI 一屏可看到“寿元剩余”和“距下一杀劫年份”。
- [ ] TapTap 构建/备案/广告要求、存档可靠性等待正式授权后再开发验证。
