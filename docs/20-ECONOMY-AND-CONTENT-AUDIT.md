# 20 · V0.5 数值试算历史记录与 V0.6 更正

> **证据等级与限制**：为本次策划检查，使用独立的**临时 Python 算术模型**验证参数、随机结果与几种预设决策路径；它**不是 Cocos 游戏代码、也不是可玩原型**，没有真人数据。脚本未写入仓库，样例政策和参数列于[19](19-FIRST-CHAPTER-ECONOMY.md)。模拟“成功率”指在该极简计算模型与**固定预设策略**内满足判定，不能解读为未来真实玩家的胜率、留存或公平性。

## 一、模拟覆盖范围
- 基本状态：世界历0、年龄16、凡人寿限80；年推进唯一，主角炼气→筑基，修为/灵石/灵材按[19](19-FIRST-CHAPTER-ECONOMY.md)结算。
- 特殊收入：世界年18、34固定二选一事件；年30独立非必需随机奖励（10%修为+80、10%灵石+20、80%无）。
- 世界年45预警、60历史杀劫；生存判定为“筑基或有护脉丹”，**第60年只有一次世界史结算**。
- 四种预设策略：**专注筑基（A）/炼丹保命（B）/不买专注心法的混合流（C）/只赚钱不收灵材的分心流（D）**。
- 针对修为年产量 -10%、标准、+10% 三个外部系数档，每档分别跑**每策略1000个种子**，共 **12,000个独立首段方案**；不是把12,000个人生连续放进一个不断推进的真实世界线。
- 使用 `random.Random(seed)` ，种子取 `0…999`；极简随机只影响可选额外修为/灵石，不改变固定灵材来源。未建模复杂功法、装备强化、NPC社会或长期多篇章。

## 三、12,000个简化场景压力测试

下表每格表示该策略在 **1,000个独立种子中的模型幸存次数**（不是正式玩家胜率）：

| 修为生产系数 | A 专注筑基 | B 护脉丹 | C 混合 | D 分心 |
| --- | ---: | ---: | ---: | ---: |
| **-10%** | **1000** | **1000** | 0 | 0 |
| **标准** | **1000** | **1000** | 0 | 0 |
| **+10%** | **1000** | **1000** | **110** | 0 |

### 从这一组结果可以成立的判断
- A与B不依赖稀有机缘也可过首劫，满足两条稳定规划路线的最低逻辑要求。
- 未投资生存方案的玩家可能失败，世界事件才真正有压力。
- C仅在+10%生产力且部分稀有修为奖励时可过关；这是本极简模型给混合玩法留的临界空间，但**11%的表现是抽样结果，不是预设的概率承诺**。
- A在新的逐年模型中年53筑基而B在年48完成丹药；A长期寿元与生产力更强，B能更早确定保命且节省部分灵石。两者的资源需求不一样，但**无法仅凭此表证明二者已平衡**。
- 随机奖励完全没影响 A/B 的生存资格，这是主动设计的**运气不锁主线**。

## 四、数值陷阱与本轮修复记录
最初测试用的筑基门槛是 **1400修为**，这使“不买专注心法、仅选采集+一次顿悟”的混合流在世界年58也能筑基，比炼丹所需灵材少、灵石成本也低，形成接近**占优策略**。将筑基测试门槛调整为 **1650修为**后：
- 专注流在标准产出下仍可年52筑基；
- 炼丹流年48完成护脉丹；
- 混合流在标准产出下不再保证过首劫。
这属于**策划参数修正**，不是已经找到最优平衡。日后对所有政策进行搜索/优化可能再次找出占优漏洞。

## 五、轮回点套利检验（首轮）
- 时间分奖励 `floor((Y/20)^1.5)` 在有效年份25、40、60、80、100时分别是 **1、2、5、8、11**；100年后软增益递减。
- 在首次成就已经拿过的情况下，**25年浅层轮回≈1RP/25游戏年**；**60年仅炼气≈5RP/60年**；**60年筑基≈8RP/60年**。简单年均收益为 **0.04 / 0.083 / 0.133 RP/游戏年**，说明**这一组预设**暂未鼓励三秒短刷。
- 首次失败可领6RP，足以购买3RP的第一个长期升级，保证玩家看见失败后变快。
- **重要不足**：时间效率不等于现实分钟效率；自动倍速、RP带来的产出加成、延寿跨几百年、主动转世对世界的时间后果尚未进入策略优化。不能因此声称永久经济已稳。
- 账务安全：首次炼气/筑基/灵潮成就必须账号级去重；RP如果尚未结束人生，只展示预估，不能提前花可变动的未来奖励。

## 六、随机事件模板密度模拟

为了测「前五世会不会缺少新鲜感」，另用一个**独立且简化的事件曝光调度模型**：
- **12个模板**：2个只出现一次的教学、4个常规、2个遗物/魂印联动、2个灵潮余波、2个稀有。
- 第一世主要抽 **4个事件**（包括2个教学），第2–5世各抽 **3个主要事件**；两种稀有可选事件分别约7%触发，不用于保证基本内容密度。
- 比较两种发放：**天真随机**（从当前可用模板等概率抽），以及**新鲜度优先**（优先推荐玩家此前尚未见过的模板，同次数随机打散）。
- 用0…999共 **1000个种子**跑5世曝光，共5000条模拟人生；这里只统计“未见过的模板数”，不含不同选项/结局的差异。

| 人生 | 天真随机：平均全新主要模板 | 新鲜度优先：平均全新主要模板 |
| --- | ---: | ---: |
| 第1世 | 4.00 | 4.00 |
| 第2世 | **2.28** | **3.00** |
| 第3世 | **1.38** | **3.00** |
| 第4世 | **0.88** | **0.00** |
| 第5世 | **0.54** | **0.00** |

**核心发现：** 单靠12个模板，即使合理排期，第4世也没有全新的模板可发。应采取「**新模板优先 + 同模板条件分支 + 世界因果改写结局**」的混合方案，而不是不顾制作成本硬堆30个完全独立事件。

## 七、V0.5 对内容的改进建议
- 维持 **12个事件主模板**，但为关键常规、余波、遗物联动事件补至少 **6组实质不同的条件变体**（同一角色/地点，不同费用、风险或收益），为第4–5世提供机会成本的变化。
- 事件“新鲜度”应按 `templateId + meaningfulBranchId` 记忆，而不是只按templateId；不会影响世界史事件唯一性。
- **一次世中2–4个重大选择**是目标区间，但不允许为了达到计数而让第60年灵潮重播。
- 对稀有事件只保持意外奖励功能，不能让低概率成为唯一能产生本世目标的来源。
- **不能宣称目前已经保证前五世全程新鲜**。这至少还需要条件变体的成本/效果表与可重复的事件池测试。
- 事件导演应先看当前生存目标、世界阶段和已见过的决策，再选择可用事件；不是无条件发玩家未见模板。

## 八、下一轮仍需验证/尚未完成
1. **自动策略搜索**：不止四种人工挑的决策，尝试策略组合穷举，发现意料之外的严格占优套路。
2. **多世世界线模拟**：从死亡世界年60→第二世世界年62→未来160年的实际事件与遗藏找回。
3. **条件变体事件表**：具体6组分支必须做到不只是换文案，要变更选择和收益。
4. **RP升级后再模拟**：第一世失败6RP投入不同升级，第二世是否真正加快发育又不完全破坏生存压力。
5. **生命周期边界**：跨第45年预警/第60年事件的行动精确停点、年龄寿终同年冲突与转世账务幂等。
6. **真实体验评审**：实际手机点击、空窗时间与随机事件阅读成本还没有试玩数据，7–10分钟是设计目标。

到这些事项验收前，本报告只支持将第一篇章标记为 **“具备可计算的两条保底通关路线，但尚未平衡和可玩验证”**，不能冻结最终PRD。
