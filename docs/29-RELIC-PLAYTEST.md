# 29 · 遗物×轮回×图鉴×日志×成就的实际体验整合 V0.7

> 目标是**提高单段主动游玩中的选择密度**，而非增加五套独立手操。参考 [17](17-SESSION-PACING.md) 的首段7–10分钟，遗物规则见[25](25-RELIC-VAULT.md)、经济见[26](26-RELIC-ECONOMY.md)、图鉴/日志/成就见[27](27-CODEX-JOURNAL-ACHIEVEMENTS.md)，实测边界见[28](28-RELIC-BALANCE-AUDIT.md)。

## 一、系统融入现有4入口
| 原入口 | 新增但不占主导航的内容 | 应尽量自动的操作 |
|---|---|---|
| **修行** | 显示两件遗物对修为生产的实际影响、突破前后数值 | 产修为、已精通的低阶步骤 |
| **机缘** | 探索遗物/线索，子抽屉「遗物库：已收录/激活/强化/碎片」 | 普通探索结算、重复遗物转专属碎片、满级溢出变通用 |
| **应劫** | 明确哪件遗物影响哪些生路、同类加成上限 | 预计生存门槛，禁止在灾劫结算中途换装 |
| **轮回** | RP解锁遗物第3–6槽；「世录」查看图鉴、日志、成就 | 结算一次成就、一条关键人生摘要、永久图鉴状态保留 |

## 二、首次两世的具体体验钩子（非强制剧情）
**第一世**：
1. 进入游戏仍旧先做修行突破，**不立即抛出七档品质抽奖界面**。
2. 世界历24年前后进行一次基础探索，**确定性解锁W01白色「旧纹吐纳玉」**，打开轻量「遗物库」提示；白遗物只是成长助力，单凭它过不了世界历60灵潮。
3. 第一次打开「机缘→遗物」能看见**初始2个可激活槽**，第二槽空着；图鉴只展示当前版本可获取的少量影子。
4. 拾取旧纹护心玉的现有**前世实体**剧情保持原样，另行记录，不要把同名“旧纹吐纳玉”与护心玉误识为同一物品。
5. 灵潮成功或失败后，日志记一个世界史事件、人生结算记一个死亡/选择事件，成就首次登记只发一次奖。

**第二世/初次再历练**：
1. 主角携带此前已经收录的白遗物共鸣（其账号装备位永久保留），并在本世探索/历练完成保证性的**G01「凝息珠」**解锁。
2. 两件修为遗物组成有感但有限的**+8%基础增幅（Lv1合计）**；玩家也可以拿一件换采药类/线索类遗物，理解**两个位置只能做一部分事**。
3. 世界历60已发生，不会强迫重新过灵潮；当世依赖余波事件、寿限、前世实体护心玉取回等目标进行积累。
4. 获取重复W01→专属碎片+1；可以选择把它升至Lv2(+0.5个百分点)，或暂留碎片。碎片交换只有确实拥有冗余时才提示，不提前要求背配方。
5. 轮回点如果充足且已收录3种遗物，可选择花8RP解锁第3槽；**优先升级效率 vs 开新槽 vs 遗物追踪**的权衡成为新层次策略。
6. 图鉴显示1/8→2/8、日志出现“前世旧物取回”、成就“灵藏初开/两仪相承”解锁，但**不弹三次重复领取奖励**。

## 三、第三世到第五世的内容密度变化
- **第3世**：初次出现有价的重复探索、分解/指向换碎片（如果资源足够）；玩家开始选择偏修行、采材、前世寻找哪种两件配置。
- **第4世**：通过历史因果＋遗物标签解锁一个真实**可选新事件分支**（例如持旧井指针寻回遗藏快2年），而不是把同一“开宝箱”按钮反复点。
- **第5世**：根据已收录种类与RP进度解锁第3槽的可见目标、利用成就引导玩家尝试另一条生存策略；不能保证玩家在第5世前拿满8件或买到第4槽。
- 每世通常仍只有2–4个重大选择事件；遗物库和成就不额外强迫玩家每次手动清空奖励页。

## 四、三种配装的明确应用场景
| 配装倾向 | 示意（初期2槽） | 真正的取舍 | 要测试的风险 |
|---|---|---|---|
| **精进修行** | W01吐纳玉 + G01凝息珠 | 更快筑基，少留出材料/信息收益 | RP旧识经脉再叠加导致太快通过灵潮 |
| **药材求生** | W02山药篓 + G02青囊药匣 | 更有利于准备护脉丹、没有大修为加成 | 不能把同一采药事件重复结算，也不能免费凑满5灵材 |
| **前世寻踪** | G03旧井指针 + W03观风铃 | 更快定位实体旧物与地区机缘，修为慢 | 不能通过寻踪重复复制同一实体，也不能无成本得到蓝/紫 |

**材料辅助总上限候选**：对同一生涯的**同一次基础采材事件**，所有装备合计**最多+1灵材**，且每世最多一次；如此一来，不会仅凭两张低档遗物把第18年一次采集+3变为+5，直接免掉第34年原有的资源取舍。丹修仍有优势，但不会无脑过劫。

## 五、操作密度与复杂度审计
| 项目 | 当前边界 | 说明 |
|---|---|---|
| 常驻主入口 | **4** | 不另加“遗物/图鉴/成就/日志”四个底栏 |
| 初期遗物激活 | **2槽** | 之后可解锁至6，未收录的槽位不强行填满 |
| 单次拾取遗物 | **1次获得弹条** | 第一次收录写图鉴/成就/日志，重复只显示碎片摘要 |
| 装备 | **点击已有遗物→点击替换槽** | 不在每次开局强制逐个确认 |
| 升级 | **达到碎片阈值才提示** | 无需逐片进度弹窗；Lv10后溢出自动分解 |
| 日志 | **自动记录关键事件** | 不逐年记录+15修为 |
| 成就 | **自动判定与登记** | 不重复在图鉴/成就/轮回发同一奖励 |
| 历练/探索 | **有年份/资源成本与次数约束** | 不因添加遗物系统额外产生无数刷箱动作 |

## 六、首章经济和数值的影响
- 第一世的第一件遗物在世界24附近取得，**不改变世界0–24的原有修行成本**；效果Lv1仅+3%修行产出，剩余世界年约36年，对已有修行路线是有限增益，**不自动满足任何历史斩杀线**。
- 第二世拥有W01+G01后，Lv1共+8%，比RP一次性旧识经脉+25%小得多；**它们与RP加成的实际乘法/加法顺序必须固定**，见[26](26-RELIC-ECONOMY.md)。
- 三槽8RP的购买不能强迫玩家放弃原本3RP修炼升级才能避劫；该槽是更多构筑工具，不是通关门槛。
- 长寿期可通过不同的遗物带来“灵材采集/线索/修炼”切换需求，而不是延长读秒等待。
- **碎片刷取不直接发RP**，完成一个图鉴成就只能一次性结算已有的成就/线索，不得被碎片分解/合成反复激活。
- 有关第160年的历史关口仍然只是**待开发内容边界**：遗物不能用来假装已完成该关的求生验收。

## 七、MVP分期决策
**MVP-0 核心手感验证**：2槽、4件功能不同的遗物（至少1修行/1采集/1线索/1生存辅助）、收录/换装、升级到Lv3、1次重复碎片、最低限度成就与日志。  
**MVP-1 第一章内容补全**：8件白绿蓝可收录遗物、Lv1–10完整曲线、同档兑换/升档规则的可见但受限界面、图鉴日志成就轻量完整页、3槽购买作为候选。  
**未来**：第4–6槽、高档遗物、新章节隐藏内容、批量定向探索、彩色唯一遗物与高层构筑。切勿因文档有76件计划就将76件和六槽都当第一版交付。

## 八、真正开始开发前的阻塞项
- 有8件完整的可执行遗物效果定义（含具体整数结算、哪种事件只触发一次）、获取事件/定向探索时间与资源收支；
- 进一步模拟W01/G01、RP ×1.25、青囊/山药篓对世界60筑基/炼丹两条路线的影响；
- 3槽扩张费用8RP对“先修炼加速”购买顺序的敏感性检验；
- 同档、升档碎片互换的所有边界状态测试（Lv10、满仓/无损坏、不可升级遗物、世界线回溯）；
- 50–100世成就与日志压缩后的存档大小/UI性能测试，需等实际原型出现；
- 真机观察**遗物是否让一次主动游玩增加超过2–3次没有策略意义的点击**，如增加则继续简化。

## V0.9 遗物双槽在主修对照里的实际意义
玄/丹×无遗物/成长双件（W01+G01修为+8%）/工具双件（W02+G02采药+1材料）×RP无/一次+25%，在[33](33-XUAN-DAN-ACCEPTANCE.md)进行反事实条件测试。成长双件可使玄修无RP筑基年52→49，但丹修的护脉生存完成年份不受这8%修为倍率影响；工具双件提供丹修未来丹材余量，而不只是白卡数值落后。
**这些是账户已解锁后可以想象的压力测试配置**，首次世界年60不应无来源自动装备未来才解锁的G01和RP。遗物实际首次获得的世界年、界面配装操作和对RP经济的影响仍待完整联合模拟。
