# 43 · 墨青金环：从概念稿到游戏资源 V1.4

本轮将用户选定的竖版仙侠视觉方向从一张不可用的概念展示稿拆为**可替换的六个独立游戏素材**，不拿概念稿上的伪中文字/UI数值当真实按钮。

## 已入库资源

- **环境背景**：浮岚仙境云海（`prototype/next/assets/backgrounds/immortal-realm.webp`）。
- **独立角色**：行走修士、静修者、青玉同道（全部带透明通道）。
- **功能场景**：游历机缘、应劫魔潮两张卡面。
- **附属文件**：可读的 `assets/README.md`、机器可用 `assets/manifest.json`、`assets/index.html` 画廊。
- 总体积约1.63 MB，主站按需加载；保留源插画的视觉层次，但将文字/UI控件完全分离。

## 页面实施（V1.4第一阶段）
`prototype/next/style.css` 轻量引用4张实际插画：顶部用云海风景，修行页显示低干扰静修人物，营生摘要使用机缘场景背景，应劫摘要用魔潮风景。其它2张先进入素材库，待人物锚定或后续场景启用。保留原四主导航、可阅读数值、响应式规则和V1.2游戏状态机。

## 后续图层与实现规则
1. **UI功能优先**：对比度/焦点优先，底色罩住图片；屏宽320px仍应完整显示境界、职业Lv、材料/费用。
2. **分层管理**：资源以背景/人物/场景分类，未来再增`ui/`（分离边框、图标、按钮装饰），不把不同状态的图片烘成同一张大图。
3. **身份严谨**：青玉同道只是通用插画，不代表顾南枝正式立绘；若用于故事角色需另行做人物锚点一致性校准。
4. **移动资源预算**：更高分辨率源图可另行归档；网页使用可控尺寸WebP，不用3 MB以上PNG直接铺满每屏。
5. **校验**：`manifest.json`列出每张独立资源的SHA256、尺寸、alpha和字节数。GitHub blob在`main`和`gh-pages`同步，页内路径应相同。
6. **禁止改动玩法**：本轮不改`game.mjs`、事件和RP存档，不允许美术提交顺手调整数值。
