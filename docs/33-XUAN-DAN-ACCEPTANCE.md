# 33 · 玄修 vs 丹修：同条件玩法差异验收 V0.9

> **结论先行：机制分化“条件通过”，游戏乐趣“未通过真人验收”，V0.9候选数值“尚未冻结”。** 依据为本轮一次性临时 Python 年度账本模型，**不是 Cocos 游戏代码、真人操作、产品留存统计或完整经济最优解**。受控测试可复现设计方向；所有数字须与[34](34-ALPHA-TWO-PATH-SLICE.md)的试验规则一并理解。历史第60年灵潮**在同一世界线只发生一次**；本文同时比较玄/丹时使用两个**反事实的新世界初始状态**，并非在同一条世界线反复刷首劫。

## 1. 为什么要做这次验收
- 不接受“玄修修为+20%，丹修采药+20%”作为两个职业。
- 检验：同样的资源、年龄、世界年、两槽遗物池、RP条件下，**玩家必须做出的关键决策是否不同**，获胜后是否有不同的长线发展机会。
- 额外检验：个人命关「心魔问境」能否增加策略密度而不加新底栏、个人命关是否会抢占原世界历史事件ID；有不合理死档/点错无反馈/专属动作负收益立即记缺陷。

## 2. 受控环境和证据边界
沿用[19](19-FIRST-CHAPTER-ECONOMY.md)第一篇章首世基础：
- 世界历0、年龄16、凡人总寿限80；炼气120、筑基240。1年=1次生产：凡人修为15/年、炼气28/年、学专注后40/年、筑基60/年；灵石+2/年。
- 炼气180修为；专注吐纳30灵石+2年；筑基1650修为+45灵石+3灵材+2年；普通护脉丹55灵石+5灵材+3年。
- 本世第18年和34年分别有可规划的二选一资源机会：18年采集3灵材或换灵石35；34年采集3灵材或参悟修为180；所需采集各耗2年。
- 本世**39年个人命关**，世界年45预警、60第一道历史灵潮；世界60只判**之前已经完成的**筑基或已完成护脉丹，**动作刚好在60年结束的生存资格不能当作自动成功**（事件/动作同年先后优先级需最终事务化明确）。
- 首轮对照 **RP=0、遗物加成=0、无稀有事件**；另做交叉使用“成长两件：W01+G01共+8%修为”“工具两件：W02+G02一次采药+1材料/可选省材配方”与“RP修为+25%”的压力测试。**这些两件满配/RP首劫场景只是对照沙盒，不意味着真正第一世能拥有第二世才解锁的G01或RP**。
- 行动花费的年份和自动修为/灵石产出共用**一次**流水线；个人命关与配方花费独立于全球历史事件，无直接发RP。特殊“灵材意外损失”另属**假想逆风压力测试**，尚非已实装常规事件/掉率。

## 3. 一张共同命关，不同解决代价（V0.9候选）
**心魔问境·本世第39年**：3个可读选项，均为普通个人试炼而非世界斩杀线。
| 选项 | 硬条件/消耗 | 结果 | 类型 |
|---|---|---|---|
| **以修为镇心** | 当时修为≥900；实际扣150修为，耗1年 | 命关成功+当世遗物通用线索/碎片**1份**（暂定，不重复发首达RP） | 玄修偏好、其它主修也能用 |
| **以药定神** | 灵材1、灵石15、耗2年 | 同类命关成功+奖励1份 | 丹修偏好、其它主修也能用 |
| **暂避心魔** | 耗2年 | 保全性命，无该命关奖励 | 公共保底退出路线 |

**不能从“奖励碎片1份”反向造出未解锁的彩遗物**。当世首通奖励的稀有度、来源ID须在实际遗物经济里细化。当前只验证“愿意为明确奖励付出哪一种成本”，不宣称已确认该奖励长期性价比。玩家可能主动跳过以保住筑基机会，**这是合法策略，不视为错误游玩**。

## 4. 两条主修区别必须由独特行动产生
**玄修·闭关推演（候选）**：每世最多1次，耗**18灵石+2游戏年**，**下一次筑基需求修为降低140**。修为继续按正常年份生产；**技能是否划算要同时看灵石是否足够支付45筑基费用**。未购买RP时主修路线的世界年53旧基准，加入命关后“推演+镇心”例示世界年**52筑基**，已是**新试验**，不能和旧53直接归结为无条件增益。

**丹修·定方炼丹（候选）**：丹修在“已学普通护脉丹”的同一张制作卡上额外可选：
| 方案 | 灵石 | 灵材 | 年数 | 结果 |
|---|---:|---:|---:|---|
| **普通护脉** | 55 | 5 | 3 | 灵潮防护，炼气寿限120 |
| **省材定方** | 55 | **4** | **4** | 同等防护，多花1年换省1灵材 |
| **驻元护脉** | **80** | 5 | **5** | 同等防护；炼气本世总寿限**至多140**，一次性不能重复堆叠 |

驻元不是免费加寿：+25灵石、+2年换较长后续发展时间，需更早规划；若世界关口只剩4年，UI必须直接显示**来不及**，不允许超时动作莫名通过。它目前的收益与后期炼丹/突破的时间价值尚未正式数值优化。玄修仍可学普通护脉丹，丹修仍可冲筑基，但非主修不白得对方特色卡。

## 5. 首轮“可复查的两个人生”
所有数据是在**相同RP=0/无遗物加成/世界年0起**、不触发稀有掉落的反事实对照：

| 项目 | 玄修：冲境 | 丹修：驻元护脉 |
|---|---|---|
| 第18年 | 采材3 | 采材3 |
| 第34年 | 参悟修为+180 | 再采材3 |
| 前期关键投入 | 专注吐纳30石2年；闭关推演18石2年 | 不学专注；把灵材预算留给试炼和药方 |
| 第39年心魔 | 修为镇心：扣150修为、1年 | 药材定神：1灵材、15灵石、2年 |
| 世界年45后 | 保证筑基材料与冲境 | 攒够80石、5灵材，炼驻元护脉 |
| **完成关键生存准备** | **第52年：筑基** | **第53年：驻元护脉丹** |
| 第60年 | **均幸存** | **均幸存** |
| 第60年境界/总寿限 | **筑基/240岁** | **炼气/140岁** |
| 第60年剩余灵石 | 27 | 25 |
| 个人命关奖励计数 | 1 | 1 |
| 关键决策与不同短板 | 追修为与境界，花灵石换省突破年数 | 抢材料与药方，花灵石买生存和额外寿限 |

**重要对照**：丹修选择**普通护脉**时能在**第48年**完成、总寿限120，剩余灵石50；选**省材**第49年完成、留1材料、寿限120；选**驻元**第53年完成、寿限140。**这才形成丹修自己的“快保命 / 留材料 / 久续命”真实取舍**，不是每次必点“多花1年省1材”。

## 6. 玄修“专属能力反而拖慢”是本轮重要发现
在同样资源路线＋心魔镇心的模型里，闭关推演非无限增益：
| 额外永久/遗物条件 | **不推演**完成筑基 | **推演**完成筑基 | 决策结果 |
|---|---:|---:|---|
| 无RP、无遗物 | **56年** | **52年** | 推演节省4年（额外花18石） |
| RP修为+25% | **46年** | **49年** | **推演反而慢3年**，缺口由修为变成灵石 |
| RP+25%且成长两遗物(+8%) | **40年** | **49年** | **推演慢9年**，资源短板转移 |

**不要悄悄给玄修“已解锁必自动释放”的特技**。这不是模型错误，是真正的经济反直觉风险：永久修为增长后，更多闭关消耗灵石可能抢走了筑基的45石门槛。UI必须预览“若采用此方案，预计筑基最早年/灵石缺口”，允许**明确跳过**；自动化以后只可对已确认不会损害玩家目标的动作建议执行。代价的存在也给高阶增量玩家重新优化构筑的动力。

## 7. 遗物与RP交叉测试的结果和限制
六组条件组合（RP无/有+25% × 遗物空/成长双件/工具双件），固定使用对应主修推荐思路：

| RP+25%? | 遗物配置 | 玄修：按当前最优选是否推演的筑基年 | 丹修：驻元护脉完成年 | 丹修驻元寿限 |
|---|---|---:|---:|---:|
| 否 | 无 | 52 | 53 | 140 |
| 否 | 成长双件 | 49 | 53 | 140 |
| 否 | 工具双件 | 52 | 53 | 140 |
| 是 | 无 | **46（跳过推演）** | 53 | 140 |
| 是 | 成长双件 | **40（跳过推演）** | 53 | 140 |
| 是 | 工具双件 | **46（跳过推演）** | 53 | 140 |

丹修的“成长双件”**不改变护脉丹制作的截止年**，说明单纯堆修为在丹修的第一目标上并非最优；工具双件使合法采药剩余材料增加，改善续命/后续探索选择。对比是**不同目标的决策特征，不等于丹修长期绝对弱**。高级RP玩家如希望直接筑基也能改策略，**不锁职业**。

**数值审计范围**：另穷举**1,152个有意设定的简单策略组合**（2主修×3遗物状态×2RP×2目标×2个第18年选项×2个第34年选项×专注开关×特技开关×3个心魔选项）。组合含不合理/受支出约束无法执行的政策，因此“多少组合通关”**不是胜率、也不能证明两职业平衡或绝对最优解**。它仅用于寻找可行路径和反例。

## 8. 逆风压力测试：假设第37年损失1份灵材
这是一个**未在现有MVP事件池中正式设定的反事实**，不是声称所有玩家都将经历随机掉材。给出一条共享的、**本世最多一次**的应急药庐选项（须确有材料缺口、花3年+12灵石→收回2灵材，复用资源事件卡，不新增第13模板）后：
| 政策 | 无材料损失 | 损失1份材料 | 该选择的价值 |
|---|---:|---:|---|
| 玄修镇心+推演筑基 | 年52筑基 | **年55筑基**（使用应急药庐） | 冒险会推迟冲境，灵石余量下降 |
| 丹修普通护脉 | 年48完成 | **年48完成**（应急药庐、额外花12石） | 换灵石保障速度 |
| 丹修省材护脉 | 年49完成 | **年49完成**（无需应急采购） | 多花1年，节省应急成本 |
| 丹修驻元护脉 | 年53完成 | **年59完成**（使用应急药庐） | 多争20岁寿元但接近斩杀线，非常紧张 |

所有成功都要求**完成年<60**；世界年60先后优先级尚待真正事务测试。**应急采材的3年12石只是候选救济成本，不应无条件重复利用为资源印钞机**。如果将来引入其它随机损耗，必须重新验证最坏情况或提前向玩家预警；不应把未预告的随机扣材当作硬性死亡陷阱。

## 9. 操作密度与“是否真的不同”的评定
| 评价维度 | 设计阶段结果 | 判定 |
|---|---|---|
| 首劫前两条不靠稀有掉落的生路 | 两条均完成且幸存 | **通过** |
| 两职业实际事件和主要操作顺序 | 玄修：专注→推演→修为镇心→突破；丹修：采材→药材定神→选择配方 | **通过** |
| 每条特色行动有非自动最优成本 | 玄修在高RP下负收益；丹修3方有时间/灵材/后续寿元取舍 | **设计条件通过** |
| 两套遗物有不同情境作用 | 成长双件帮助玄修突破，工具双件给丹修后续材料 | **模型通过、未证明玩家偏好** |
| 个人命关不会重播世界史 | 按lifeId触发，世界事件按worldlineId一次结算 | **规则通过，代码未验** |
| 角色仍然可以跨职业改路线 | 任一主修可用正常丹/突破方案 | **可行** |
| 操作数量可控 | 推荐首段关键操作玄修约6、丹修约4（不含打开UI等） | **预估符合，未经真机** |
| 中途随机机缘足以**改变最佳方案** | 只测试了1次材料损失及固定两遗物，不包含事件导演全池 | **未通过充分验收** |
| 第一世到第五世长期“愿意再玩” | 无真人测试/真实长寿章节未实现 | **未验收** |

**总裁决：** 允许作为**两条具有不同资源策略和延寿后果的主修设计候选**进入MVP-0 PRD；**暂不冻结**技能数字、配方价格、个人命关碎片奖励或实际手感。核心角色区分通过数值反例测试，但“好玩”必须靠交互原型与真实试玩确认。

## 10. 必须整改的四个缺口
1. **玄修闭关陷阱**：无RP时有利，RP堆起来会拖后腿，不能自动强制放技能；操作卡需显示预测，并有不使用的合理收益。
2. **丹修配方三选一不能伪装为三个新面板**：同一普通丹方扩展为分支；驻元需要一次/世封顶，不允许反复同一药堆加20岁。
3. **第39年命关的碎片奖励还没有验证经济性**：要用已有探索来源ID和账号首次发奖去重，不可增加刷RP机制。
4. **首次60年与未来160年、真实长寿期尚未联通**：不能仅凭一次控制模型宣称五条道途、跨世复玩、完美平衡均已通过。
