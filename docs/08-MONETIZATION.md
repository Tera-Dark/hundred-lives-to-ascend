# 08 · TapTap IAA 变现策略 V0.3

**目标**：手机端 Tap 小游戏，IAA 自愿激励广告，不做内购或强制插屏。具体广告 SDK 接入、资质和审核要按开发阶段最新 TapTap 官方资料核查。

## 核心公平原则（双时间轴版）
- **不销售寿命、不用广告续命、不让广告越过纪元斩杀线**。修行境界、延寿药物、法宝与避劫路线必须可由普通游玩获得。
- 轮回点 **RP**、化神道果 **DP**、飞升界源 **EP**、首次寿龄/纪元纪录、关键魂印、前世实体遗藏**不依赖广告**；不得用“看广告永久三层点数翻倍/直接购买高阶解锁”制造强迫。
- 任何广告失败、取消、未填充不得加速世界年、触发死亡、扣灵材或使前世遗藏消失。
- 看广告不能随机重抽已经锁定的机缘表，也不能让同一实物通过回调产生复制品。
- 不把广告 UI 放到死亡结算、历法致命预警及轮回确认的核心按钮上。

## 候选自愿激励位（上限建议两个，正式 MVP 再选）
1. **机缘线索辅助**：额外揭示一次非唯一世界事件/秘境线索的提示，不直接给予突破寿元或避劫的必需品。
2. **重复修炼便捷加速**：已解锁基础自动化后的可选短时便利，不能为变现而人为压低不看广告者的成长效率；加速不能静默越过个人死亡或世界事件。
首轮更应验证“不看广告体验是否有趣”，之后用观测数据决定是否保留任何广告位。

## 多篇章变现限制
- 高阶篇章的挑战修饰符、入口资格与首通奖励不设置广告付费墙；玩家不能因为不看广告而被排除在化神、飞升或新纪元外。
- 广告加速不允许跨越未经玩家确认的寿尽/斩杀线，也不能自动完成证道或飞升的独特决策。
- 高级章节玩家若较少使用广告，应优先优化长期乐趣，**不以人为制造长等待来提升曝光次数**。

## 运营观测
关注首次突破、第一世结束、第一次轮回、首次实际寻回前世物品、首次跨过纪元斩杀线、次日留存等节点；随后才观察广告观看率、填充率、正确发奖率与广告后流失。**不要预设 eCPM、用户规模、广告收益。**

## 平台与工程边界
仅授权后以独立 AdAdapter/mocked provider 开发；激励完成后幂等发奖，前后台恢复不得重发。普通 Tap 小游戏的 Dirichlet/TapADN 路线与 H5 小游戏 SDK 不能不加核查混用。

## V0.7 遗物收集和IAA公平
**不销售遗物盲盒、彩遗物、强化碎片倍数、直接开六槽、探索必需门票、同档兑换手续费豁免**。七档稀有度与隐藏图鉴均可通过普通游玩和有条件的探索/历练获得；高档剧情类不靠观看广告获得。图鉴/日志/成就自动记录，不能为了增加广告曝光故意让玩家反复打开升级界面。可选便利广告不得改变天劫生存的必备条件或造成重复碎片发放。

## V0.7 IAA与遗物公平性
不售卖遗物盲盒、彩遗物、强化碎片倍数、六槽直接开启、核心探索票券或同档兑换豁免。高档隐藏遗物靠正常修行/剧情/挑战获得，不靠广告抽中。图鉴/日志/成就自动记录，不为了广告增加领奖菜单；广告失败不能损失已经取得的碎片、永久装备位、前世实体或游戏年。
