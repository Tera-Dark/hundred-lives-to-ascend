# 02 · 核心游戏循环与时间机制

## 核心闭环
**选命格/出身 → 自动修炼增长 → 资源与事件选择 → 功法/备劫构筑 → 第100年大劫 → 纪录与轮回点 → 选择遗泽/常驻天赋 → 新世。**

每世的中目标是境界突破、获得有趣的机缘组合、解锁一项抗劫手段；外目标是刷新渡劫纪录和永久传承。失败不是终止游戏，而是一次能解释原因的结算。

## 时间框架（首次提案，未锁定）
- **游戏内时钟**以“年”为资源上限，每世最多100年；初期体验以约 8–12 分钟/世为**测试目标**，不是对玩家的现实等待要求。
- 常规修为自动增长；大型行动（闭关、秘境、炼丹研究等）除资源外还可能消耗 1–5 年，制造轻量时间分配抉择。
- 暂停/倍速功能将根据引导解锁；重要的不可逆抉择出现时自动暂停年份推进，避免读文字时被倒计时惩罚。
- 空闲可以加速跳过无事年份；不能靠极速跳年重复结算、无限刷轮回点。
- 用户后台/断线时不触发不可撤销的战败与轮回：恢复游戏再由玩家确认大劫结算。具体离线模拟需与 TapTap 生命周期能力一起验证。

## 一世三个阶段（体验目标）
| 年份 | 核心关注 | 玩家获得感 |
|---|---|---|
| 1–25 年 | 出身、修炼、第一次突破 | 迅速看懂“修为/境界/时间” |
| 26–65 年 | 机缘、功法取舍、小型备劫建设 | 这一世成为什么流派 |
| 66–99 年 | 将积累投入防线，补足短板 | 时间紧迫但有决策，不是最后一分钟堆按钮 |
| 100 年 | 多阶段大劫及世界纪录 | 反馈成败原因和新跨世奖励 |

大致年数只为节奏规划；高轮回可自动跳过已被碾压的开局段，保留新的选择。

## 四个固定主入口
- **修行**：境界、功法、修炼效率、闭关与突破。
- **机缘**：事件、秘境、稀有遗物、流派机会。
- **备劫**：预告、抗劫配置、丹器阵加成、战斗表现。
- **轮回**：轮回点商店、遗泽、纪录、主动提前结束本世。
系统解锁作为对应入口的子页或卡片，导航绝不指数级膨胀。

## 每世必须有的决策
至少存在“继续修为突破 / 为大劫保存资源”“风险秘境 / 稳定发展”“保留遗物 / 立即拆解资源”等方向相反的选择。不同道路至少有机会到达第一阶段成功，不能要求唯一攻略。

## 大劫战斗
战斗是**可解释的多阶段自动结算+清晰特效**，而非纯战力大小比拼。
- 每阶段有一个主要压力（爆发、侵蚀、规则）和若干替代解法。
- 玩家战前查看备劫预测的“最薄弱环节”，允许有限调整一次配置；大劫中不应出现高频手动 QTE。
- 结算展示首次突破阶段、持续时间、伤害/护界、影响最大的前世选择；不虚构被动奖励。
- 第一世可失败，但**不脚本强制失败**；若测试玩家非常优秀也应可以取得有限阶段胜利。

## 提前轮回
玩家可在 100 年前主动结束本世，但必须满足最低有效成长（例如首次突破/经过一定年份）才能获得有意义点数；短轮回可能有成长优势，但不应成为唯一正确玩法。结算面板展示“现在结束 vs 继续冲击”的收益估计区间，而不是逼用户猜。

## 反无聊
- 自动化已重复的低阶突破和收集；首次出现的新决策必须手动确认。
- 稀有事件与功法组合改变战前策略，回合数不是唯一内容。
- 第一章/最初数世应引导至下一明确目标，如“撑过灵潮逆涌”“记录第一道护界符”。
- 不以常驻红点、繁复领取、强制每日任务来增加会话次数。
