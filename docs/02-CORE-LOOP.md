# 02 · 核心循环 V0.6：寿元与持续世界线的体验闭环

## 两条时间轴
- **个人年龄 / 寿元**：从适龄修士开始（示例 16 岁），年龄随实际游戏年增加；寿限由境界、命格与延寿效果决定，达到上限且没有保命手段则死亡。
- **浮岚世界历**：同样随游戏年增加，却不随普通轮回归零；个人死亡后转世要消耗小段世界过渡时间（待测），纪元大事件由世界历与剧情状态驱动。
- 两者**不会再在第100年同时自动结算**。一世可能很短，也可能跨越多个斩杀线，活得久本身就是显著的成长成就。
- 基础规则与难度具体定义参见 [10 · 时间与纪元](10-TIME-EPOCH.md)。

## 一世主循环
**选择出身/命格 → 自动修为生产 → 突破延寿 → 机缘与资源抉择 → 查看近期世界危机并准备 → 活过关口或寿终/战死 → 轮回结算 → 承世转生 → 寻前世遗藏 / 开启新世发展**。

始终维持四主入口：**修行 / 机缘 / 应劫 / 轮回**，丹药法宝阵法只是随进度展开的子系统。

## 时间行为约束
1. **世界按年推进**；常规修炼可自动进行，闭关、秘境、炼制等行动额外消耗明确的年份与材料。
2. **寿元被视为资源**：练功 5 年与外出探险 5 年有取舍；延寿丹不可无成本循环刷取无限寿元。
3. **邻近事件时主动提示并冻结关键抉择**：年份进度可以暂停/加速，弹出不可逆分支时自动暂停，不让读事件文字的时间消耗寿命。
4. **纪元关口预告**：提前显示剩余世界年数、危险类型及至少两种可理解的生存方案；不能玩家不知情就被突发强制秒杀。
5. **离线/后台**：存档精确到个人年龄、寿限、世界历和事件状态；恢复时不自动越过斩杀线、寿尽结算或强制轮回。必要时让玩家主动确认结算。
6. **长寿不等于无聊**：获得长寿以后继续有纪元挑战、流派构筑和主动轮回的正当理由。可以快捷跳过已稳定的修行阶段，但重大事件不能静默跳过。

## 首次体验段与完整一世的区别（V0.5）
- 初次世界年0至60的灵潮检查**预计7–10分钟**，这只是第一段内容目标而不是“整个角色一生”长度。可活过灵潮后继续修行，寿限上升不被人为取消。
- 第一章低阶经济参数、事件与首劫两种稳定生存方法见 [19](19-FIRST-CHAPTER-ECONOMY.md)；四种预设策略的模型结果及内容重复审计见 [20](20-ECONOMY-AND-CONTENT-AUDIT.md)。
- 下一世在同世界线不会重播世界年60的历史杀劫；要由前世遗藏、历史余波与角色寿龄突破补足内容，条件事件参见 [21](21-ENCOUNTER-DIRECTOR.md)。

## 如何死亡、如何继续
- 寿尽：个人寿元到达上限且无法延命，进入轮回结算。
- 纪元斩杀线：未满足生存条件且没有可使用的逃生/庇护手段，本世死亡并留下当世结局与世界事件后果。
- 修行/机缘风险：特定战斗或抉择可以致死，但必须提供合理风险提示。
- 主动转世：达到最小有效成长门槛后可随时轮回，放弃部分当世即时目标，换取永久收益。
- **默认下一世世界历继续、历史状态保留**；如旧世发展彻底不可恢复，提供不会抹去永久成长的照世碑锚点回溯（参见 [10](10-TIME-EPOCH.md)）。

## 单世操作与公平时间规则（V0.4）

- 一世的体验目标为 **6–9次有意义的抉择**，重大选择事件约2–4个；具体单世真实分钟数、事件模板与上限见 [17](17-SESSION-PACING.md)。
- **共用一次游戏年推进**：自动进度与闭关/炼制所耗年份由同一时间流水线结算。行动推进的年份不能同时被自动时钟再次扣除；重要选择暂停计时。
- **历史杀劫仅发生一次**：同一世界线世界年60发生灵潮后，下一世从之后的世界年出生，遇到的是灵潮余波、前世遗藏或下一道危机。首二世失败/幸存的纸面分支参见 [18](18-PAPER-PLAYTEST.md)。
- **MVP不发放离线免费修为收益**：离线不应成为免耗寿元的最优策略；后期须设计与寿元同步的停点结算才可开放。
- 主页永远显示一个主要目标和至多两个次级行动，已精通旧操作可自动化。

## 证道与高阶循环（进度解锁）
**普通循环**仍然是“修炼延寿→探索→应劫→死亡/主动轮回→RP与前世寻物”，同篇章世界线保持推进。
**中期层**：首次化神并完成证道考核后开启道果 DP，用法则槽、功法模板和减少旧操作推动下一步成长；**达成化神并不强制清空现世**。
**高期层**：飞升/破界后开启界源 EP 与高阶篇章选择；在安全节点进入新篇章将创建另一条可回访的世界线，旧篇章实物仍留旧线。详细规则见 [12](12-ERA-STAGES.md)、[13](13-PRESTIGE-LAYERS.md)。

## 短中长期目标
- **短期**：突破寿限、找到延寿灵草、完成第一份功法、处理眼前机缘。
- **中期**：活过下一场纪元关口，配置丹器阵/加入势力找到备劫路线；找回前世一件有用实物。
- **长期**：刷新本世寿龄纪录、保存稀有遗藏、改变纪元结局，积累道痕并开启更高世界规则。

## 前 3 世概念流程（可测试，非脚本固定）
| 世数 | 目标 | 新的乐趣 |
|---|---|---|
| 第 1 世 | 延寿、第一次突破、遇到首个世界预警；可能寿终或未过斩杀线 | “我能活多久”成为目标 |
| 第 2 世 | 用 RP 或魂印获得新选择、沿线索找回上世预留的实物 | 不是开局倍率重复，而是认识前世的自己 |
| 第 3 世 | 利用已知世界事件做超前准备，尝试另一套突破或庇护策略 | 开始学会改变命运而非纯堆战力 |

**不强制玩家必须在第 1 世死亡**；高效玩家可以活过第一道斩杀线并继续发展。

## 取舍设计
- 即将寿尽：用于筑基突破的灵材，还是炼制短期延寿丹？
- 纪元杀劫将到：冲击境界自保，还是投资护身法器/加入宗门获取庇护？
- 机缘出现：立刻拿去提升本世实力，还是把稀有物埋成下世遗藏？
- 纪元已极端恶化：坚持发展以找回藏物，还是回溯至安全锚点重新规划世界线？

这些抉择比多层升级树更优先；未验证的炼器小游戏、宗门管理大地图都不进入 MVP。

## V0.6 个人与世界事件的触发锚点
资源保障、普通炼器/修行任务按**角色本世修行进度**触发；例如第2世生于世界62年，于本世第18年（世界80年）获得当世基础灵材选择。世界历60灵潮则已发生，只能进入余波池，绝不为获得材料重播原天劫。详见 [23](23-CONTINUOUS-WORLDLINE-TEST.md)。

同一人生抵达世界160但其事件尚未开发时处于原型安全暂停，保存年龄/世界历/物品与待处理事件，绝不自动死亡、提前结算轮回。长寿期非广告快进仍消耗真实游戏年，遇关键选择与寿尽必须中断，详见 [24](24-LONG-LIFE-PACING.md)。

## V0.7 遗物与日志加入人生循环的方式
一世中合法探索/历练可能**发现一个灵藏图谱或重复获得已收录遗物的强化碎片**；角色当世只装备已解锁的2–6个灵藏位，剩余藏品仍保存在永久遗物库。遇到灵潮之前，不能靠拿到一件稀有遗物无代价跳过备劫；发现会直接写入图鉴/日志/成就的一次性事务，而不是多页面分别领奖。

轮回结算保留账号遗物库等级和装备方案，**不直接把前世实体带进另一条世界线**；详细边界见[25](25-RELIC-VAULT.md)、[27](27-CODEX-JOURNAL-ACHIEVEMENTS.md)。遗物探索要占用明确的游戏年份/阶段机会，和延寿、炼丹、寻旧物竞争有限人生时间。

## V1.1 核心循环优先级调整（计划，不是已实装）
**选择营生/主修→设多年营生/修行/研习计划→职业升级赚灵石→改善灵食和洞府→研习法门改变收益或开放行动→伙伴与地域打开可达新路→命关/历史天劫→继续长寿或轮回→职业/功法历史记忆让下世更快起步**。早期经营决策多，后期不断由已掌握工作与RP策略自动化取代低价值点击，让玩家聚焦长生/证道。

特别注意：V0.6旧固定修为/灵石年产被新计划按年度份额分配替代，**不能两个产出源同时获得全额**。重大探索/炼丹跨年行动将覆盖原日程的相应生产（显示机会成本），所有时间仍由单一时钟推进。细则见[39](39-LIVELIHOOD-AND-SCHEDULE.md)、原生存线需重算，初次长度约10–15分钟只是候选目标。现有 `prototype/` 未按此修改。
