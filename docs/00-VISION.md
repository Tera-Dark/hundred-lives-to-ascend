# 00 · 项目愿景与设计原则

**游戏**：《百世劫录》 / Hundred Lives to Ascend  
**品类**：修仙题材 · 时间管理 · 增量成长 · 随机机缘 · 轮回构筑 · 百年灾劫  
**形态**：单人、竖屏、轻文字+精美 2D 插画 UI、可短会话反复游玩  
**发行**：TapTap Tap 小游戏（待实际构建验证）；IAA 自愿激励视频；无内购。  
**状态**：概念/系统探索 V0.1，**尚未冻结为正式 PRD**。

## 玩家幻想
起初是无法独自渡劫的普通修士；经历无数次百年循环后，逐渐理解灾劫规律，以不同功法、丹器阵构筑获得新突破，终于迫使不可战胜的天命出现破绽。失败也是可理解、有意义的前进。

## 五根体验支柱
1. **明确期限**：世界每到第 100 年便迎来归墟天劫，玩家必须决定如何花费有限时间。
2. **明显决策**：修炼速度、机缘风险、资源投入备劫，少量互斥选择即可产生差异；不做遍布各页的“点红点”升级树。
3. **惊喜与可控随机**：命格、稀有遗物、事件组合改变本世玩法；关键信息可学习，主线不因随机卡死。
4. **轮回质变**：永久资产、轮回点、遗泽与前世记忆改变开局，并自动跳过已经失去意义的重复操作。
5. **渐进复杂度**：先修行—机缘—备劫，再按阶段引入功法构筑、炼丹、法宝、阵法、宗门辅助；仅四个稳定主入口。

## 产品边界
- 第一版重点是 **3–5 世可重复、有选择、有可见变强**，不是首发就承诺无限独特内容。
- “无限”指上限可扩展的数值、轮回、纪录和阶梯式挑战；独特世界、事件和机制仍需持续创作与测试。
- 主体验是 **个人修仙**；宗门是中后期的资源/备劫支援，不是全面的弟子模拟经营。
- 大劫是有可观测阶段与应对策略的战斗/检验过程，不是仅比较两个总战力数字。
- 必须有清晰“下一目标”、可读经济、可跳过重复动画、稳健存档、最小广告干扰。

## 第一版成功判据（目标，不是事实）
- 玩家不看广告，能自然完成第一世并理解轮回后的永久收益。
- 第 2 世比第 1 世有可感知的策略或操作变化，而不仅是同一条数值曲线快 10%。
- 3–5 世内玩家至少体验两种不同的机缘/构筑策略，看到大劫阶段进度向前。
- 单世操作无需频繁来回开七八个菜单；退后台恢复不会损失多年成果。
- 先验证游戏乐趣和留存，再考虑广告价值与接入。
