# 00 · 产品愿景 V0.2

**项目**：《百世劫录》 / Hundred Lives to Ascend  
**品类**：修仙增量 / 寿元管理 / 轮回构筑 / 纪元危机 / 前世寻宝  
**目标**：TapTap 手机小游戏（IAA 自愿广告、无内购）；Cocos Creator 3.8.8 + TypeScript 为技术预案。  
**阶段**：策划草案、无游戏代码；详细时间规则以 [10](10-TIME-EPOCH.md) 为准。

## 设计北极星
> 这一世，我能活多久？下一场天地杀劫，我能不能闯过去？前世留下的东西，今世能不能找回来？

玩家从凡人挣扎求长生，寿元是**第一且最频繁的压力**；天地纪元不断推进，具有周期性或剧情触发的、明确预警的**第二生存期限**。轮回将失败转换成知识与永久成长；玩家的前世物品和世界因果创造真正的“我在这个世界生活过”的连续感。

## 六个体验支柱
1. **寿元有意义**：升级境界能够延寿，也带来更多行动窗口；不能无限加速而让寿命完全失去成本。
2. **纪元有斩杀线**：关键世界年份有生存验收；低于门槛者可能直接死亡，但门槛可经多条策略路线满足、且事先可知。
3. **跨世有连续性**：主要转生继续同一世界历，保留部分世界状态；前世实物须经过寻回而不是无成本全继承。
4. **随机产生惊喜**：命格、遭遇、遗物与前世因果塑造这一世；基础生存不依赖罕见抽卡。
5. **内容渐进且入口少**：始终四主入口「修行/机缘/应劫/轮回」，功能根据境界、轮回纪录和纪元阶段在对应入口内展开。
6. **失败仍推动成长**：寿尽、灾难失败或主动轮回均有可解释的收益；可以进行不影响永久资产的纪元安全回溯，不能卡死。

## 产品范围与边界
- **MVP 优先验证前 3–5 世**：有限寿元下主动选择突破/延寿、一次纪元杀劫、一次真正跨世寻宝、几项轮回点质变。
- 世界与个人的两条时间线必须清楚显示；**不是第 100 年强制结束一世**，长寿修士可以跨越多个纪元节点。
- 前世因果用事件标记、持久物品和世界状态摘要表示，不在首版模拟整套复杂宗门社会。
- 长期数值可拓展，但“无限独特剧情”不可凭空承诺。
- 先评估玩法耦合与手机操作，再冻结正式 PRD；代码开发需要另行明确授权。

## 初版成功的体验标准（待测）
- 新玩家无需看广告即可理解两时钟：寿元将尽与世界危机是不同机制。
- 提前知道如何延寿、如何满足第一道杀劫门槛；失败后可获得可执行的下一世建议。
- 第一次主动回到前世遗藏地点时确实找回一件已留物品；不会复制两份。
- 第二/第三世在构筑或时局方面发生明确改变，而不是相同一世倍率提升。
