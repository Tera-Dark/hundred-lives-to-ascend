## 二、时间与动作唯一语义（用于后续所有模型）

- 时间使用整数**世界历年边界**，`worldYear=0`表示第0年开头、人物年龄16。每推进 `[t,t+1)` 一段，只给一次年产修为/灵石、年龄+1、世界历+1。
- **本世18/34/39**是出生/转世后独立的生涯阶段触发点；历史世界**45/60**是第一世的绝对预警/危机年，同一世界线首劫只处理一次。跨世后世界年60不会重播。
- 事件触发优先于该边界之后的玩家新行动；若动作覆盖事件边界，**先在事件边界中断动作**、处理决定，再继续合法的未用部分，不得从世界58发起耗5年丹药而在63倒算自己已提前免死。
- 第60年关口需在该年**检查发生前完成**筑基/护脉，不能让正好同年触发检查之后才完成的行为视为过关。这个“已完成”判定需要在未来开发测试中做更严密的事件优先级。
- 失败/成功/获得遗物/首次命关领奖各使用幂等`transactionId`；个人命关按`lifeId+trialStage`，全球灾劫按`worldlineId+epochEventId`，账号首达按`achievementId`，禁止读档或重入刷奖。

## 三、修订后同条件算术复核

### 计算输入与规则
与[33](33-XUAN-DAN-ACCEPTANCE.md)基础经济一致：凡人修为15/年、炼气28/年、学专注40/年、筑基60/年；年灵石+2；炼气180；筑基要求修为1650、45灵石、3灵材、2年；专注吐纳30灵石+2年；本世18/34年基础采材及顿悟；39年个人心魔。**玄修**闭关18灵石+2年、下次筑基修为需求降低140；**丹修**可选三种护脉配方；个人命关通过修为镇心（需≥900修为，扣150、1年）或药材定神（1灵材、15石、2年），也允许暂退。

**时点说明：** 以下是本轮一次性独立脚本采用“动作完成时才取得结果；按最早满足价格的年度决策”的输出。其它合法动作顺序可能得不同结果；这不是算法证明的全局最快方式。本轮限定无稀有掉落、无世界160关口、主动事件只包括该章既定事件。个人命关新奖励“心定印”的后续消费未计入年60前的修为收益。

| 修为额外条件 | 玄修不闭关→筑基 | 玄修闭关→筑基 | 是否应优先闭关 |
|---|---:|---:|---|
| RP 0、遗物0 | **56年** | **53年** | 有利，提前3年、耗18灵石 |
| RP 0、修行遗物+8% | **53年** | **50年** | 有利 |
| RP +25%、遗物0 | **47年** | **49年** | **闭关亏2年** |
| RP +25%、遗物+8% | **44年** | **49年** | **闭关亏5年** |

**丹修**选择第39年药材定神，首劫三种有代价配方路径：普通 **48年完成、寿限120**；省材 **49年完成、寿限120、剩1灵材**；驻元 **53年完成、寿限140**。四种修为条件下，按保持丹修当前“保命优先、不转筑基”的策略，这三种丹方**完成年份不随修为加成变化**，但丹修后来可以改修筑基，不能视为永久职业天花板。

**反事实逆风**：假设37年无预警损失1灵材，允许在有材料缺口时本世一次性耗3年、12灵石找回2灵材；在现有预设调度中玄修闭关路线约55年筑基，丹修普通48年、省材49年、驻元59年完成。这是压力测试，不建议直接在首版加入“无预告扣材”事件。说明：倒计时第60年对驻元方案很紧，UI必须发出明显警告与可退守普通丹方的提示。

### 有意义的反馈标准
- 玄修看见“此时瓶颈是修为还是灵石”。预览**同资源情境**下两种结果，若闭关更迟，则标注“此次不建议；会使筑基所需灵石延迟满足”，默认不执行，但玩家可确认出于别的计划而选择。
- 丹修看见“**快3～5年确定生路 / 多留1灵材 / 本世多20年寿限**”的量化取舍；如果后续境界已把寿限抬到140以上，驻元必须显示寿限增量为0、此时不可再用驻元续命。
- 个人命关成功只给真实的下次决策资格（心定印）和一次性账号首次奖励，不额外自动产生一套新货币。
- **无RP/无遗物**两条主修依旧分别以“筑基”与“护脉丹”活过世界60；遇到同一风险有两条保底，不依赖紫红彩稀有藏品。

## 四、后续必须真正验证的未完成项
1. 丹修在60年后若一直没有筑基，驻元多出的20游戏年是否足以解锁一次可见、可完成的独立目标；否则应删除或重写驻元，而非让玩家白花25灵石。
2. 心定印的事件额外选项必须改变有效资源/策略结果。倘若无用，**取消奖励或直接改为一次性首次线索，不增加虚假奖励系统**。
3. 旧33/34与新35出现的完成年份差异说明**测试接口/调度器仍需最终同构**；未来开发应以统一年度事件引擎验证而非硬编码完成年份。
4. 世界历160第二场灾劫、近关口出生的撤离机制仍未设计与验证，**不能宣称整个连续世界线已经闭合**。
5. 真机可理解程度、单次决策点击量、真实时长、重复三世兴趣、额外遗物奖励的首达台账仍未通过真人验收。

**冻结建议：只冻结ID、类型、行为不变量、首章功能边界；上述数值保留配置化与可调整，不冻结最终难度。**

## 五、补齐首场灾劫后的内容桥（V1.0新增候选规则，不属于已验证数值）

**世界年95·「余潮断脉」**：世界年60灵潮的**地方余波事件**，引用[21](21-ENCOUNTER-DIRECTOR.md)既有两张余波模板之一的条件分支，**不额外增加第13张普通事件模板**，更不是第二场全球斩杀线。仅在同`worldlineId`首次到达绝对世界95时结算一次；不同生命只承接其历史结果，不能复刻第95年剧情刷奖。

根据当时主角已有力量，在原「应劫」卡里展示最多3个方案：
- **修为稳脉**：达到筑基、付**10灵石+2游戏年**，暂定稳定地方灵脉；优势是省灵材，缺点是要先达到境界。注意必须提前完成费用，不得越过95事件后回填。
- **药阵调脉**：付**2灵材+35灵石+3年**，炼气及其它流派也可用；优势是不用筑基，缺点是占用后续研究材料。
- **安全撤离**：付**15灵石+1年**，或**无灵石时参与3年救济劳动**，主角保证不因该区域事件当场死亡，但**本世失去一项当地遗物探索机会**。不会出生太晚即死局。

稳脉成功在世界线保留`stableVein`结果，今后开启一次有价地方探索/功法线索；撤离保留`ruinedVein`，后世可以走较昂贵的重建/寻宝分支。**上述成本均为待测试价格，不发永久RP或必掉高档遗物，不开放另一个宗门面板。**

该桥只部分改善**世界60之后的主动选择**：下一步还需要用世界160真正可玩的关口/救济路线与个人长寿目标闭合中期，不可因添加年95地方事件就宣称长期内容密度解决。

**心定印保证实际有使用位置**：心魔成功当世获得1个可选的、**有价的**后续行动权限，最迟在本世下一次可用应劫/探索规划节点呈现（第一世通常世界45预警）；可选择**耗2游戏年领取+120修为**或**耗2年+10灵石领取+1灵材**（候选），一次性、不能转世结转、不能重复给碎片/RP。不需要新货币或独立事件模板。**上述收益尚未加入第三节数值表**，玩家可不使用；若使用应重新计算首劫最早完成年。如果实际测试不产生有价值的临场转向，宁可删除心定印，不保留空能力。
