# 本地运行、检查与故障定位

## 环境与启动

Node.js 20+、Python 3。项目无运行时npm依赖，不需要先执行 `npm install`。

```powershell
npm run dev
```

打开 `http://127.0.0.1:8000/next/`。直接双击HTML不适合作为ES Modules运行方式。8000已被本项目占用时复用已有服务；刷新页面即可加载修改。

## 新手和旧档验收

- 正常玩家：`http://127.0.0.1:8000/next/`，使用原默认存档。
- 独立开局：`http://127.0.0.1:8000/next/?slot=guide-demo`。槽名仅允许1–32个小写字母、数字与短横线。
- 测试时换一个新槽名即可得到新开局；不要为截图或测试直接清空玩家默认存档。

新手冒烟顺序：选出身/主修 → 阅读时间介绍 → 推进1年看日程开放 → “去看看”定位并切计划 → 本世2/3/4年逐步看职业/功法/灵食 → 手册重看及收起 → 炼气后应劫/丹方 → 后续机缘、同道、轮回。介绍停点受玩家策略影响，不能写死所有功能同一年出现。

旧档冒烟：保留世界年、现金、职业和NPC状态；v2变v3；原功能仍可用、旧介绍不批量弹出；下一新发现有说明。另查遗物卸下/重装、存档刷新与世界160导出。

## 检查命令

```powershell
npm run check
npm test
npm run test:legacy
```

- `check`：所有JS模块语法、相对模块引用、Markdown本地链接、CSS资源路径。
- `test`：当前69项测试，包括原19项、19功能目录/门槛/迁移、八种指定首劫策略、时间回归，以及设置/红点/音频生命周期。
- `test:legacy`：旧版10项；保证历史对照没有意外破坏。
- GitHub Actions执行相同三条命令；本地配置文件存在不代表远程CI已经运行成功。

修改经济/时间/门槛或存档传输后跑三条；仅改说明或CSS时至少执行 `check`，按影响做浏览器检查。浏览器验收建议320/390/768/1280像素、五页切换、介绍与剧情弹层、键盘焦点、主行动可见性。真机触控、长期留存和完整平衡尚需另测。

## 保存与恢复

默认 `localStorage` 键为 `bsjl-v12-current`，独立槽在其后加 `-<槽名>`。导出按钮在设置页、指引手册、轮回页与160边界，产生包含完整状态的JSON。

存档损坏时先保存原始数据到 `-recovery-<时间戳>`。如果备份或本地保存失败，页面会提示，不要马上清浏览器数据；先导出当前可用进度，开发者可检查备份并在独立槽验证恢复。设置页可导入JSON：预览年份、人物和资源，确认后先备份再替换。最近一次备份保存在同键的`-before-replace`，可在设置中预览恢复；上限1MB，坏档不替换。

## 常见问题

| 现象 | 检查位置 |
|---|---|
| 功能未出现 | 手册的开放条件、`meta.guide.unlocked`及 `content/features.mjs` |
| 介绍反复出现 | `seen`是否保存成功；是否选择过重看；当前是否独立槽 |
| 点“去看看”没有定位 | 功能的 `tab/section`是否匹配 `data-feature`；对应管理面板是否展开 |
| 有钱但行动不可用 | `actionStatus()`的资格、材料、修为、占用与60年截止原因 |
| 样式/图片丢失 | `npm run check`；`styles/theme.css`中的图片相对路径为 `../assets/` |
| 页面显示旧界面 | HTTP是否指向此仓库的 `prototype/`，然后刷新；不要误开旧版入口 |
| 历史报告脚本失败 | `reports/`中的复现针对旧基线，不是现行测试入口；使用 `npm test` |

发布分支仍为 `gh-pages`。本轮只维护本地源码，发布与公网可用性需独立验证。

## 触控与声音验收

320/390/768/1280宽度逐页检查修行（展开管理）、机缘、应劫、轮回、设置：可见按钮和summary均不小于48×48 CSS像素，无页面横向溢出。开启大字后复查窄屏；关闭插画仍能操作。红点应随资源/已读/装备空位变化，关闭提醒后全部移除。

设置刷新后保留，独立试玩槽共用本机偏好；测试完恢复默认偏好，不重开玩家进度。音乐首次在设置里开启，试听音效后调整两个音量，切后台检查暂停、返回恢复；关闭音效和音乐应各自静音。浏览器自动检查不代替耳机/扬声器与iOS/Android真机验收。振动只在设备支持时生效。多年确认取消不改变年份，确认只执行一次；主动轮回默认确认。

## 本轮QoL验收入口

详见[QOL-VALIDATION](QOL-VALIDATION.md)。导入/恢复测试只用独立槽；另开同槽窗口更改日程，旧窗口应提示刷新并停止写入。切页后浏览器返回应恢复滚动与折叠状态；再次点当前页回顶。1–5切页、N推进1年、M音乐；输入与弹层内不触发。滑杆拖动不整页重绘，音量实时生效。

音乐开启后播放《古琴幽篁》，应能从头重播、后台暂停和返回继续；曲尾采用3秒交叉淡化，若第二路暂时不可播放，原路仍有原生循环后备。冷启动音乐关闭时不应请求MP3，首屏只请求两张当前插画。
