# 03 · 轮回点、传承与回世乐趣 V0.2

> 规则目标：死亡不亏、轮回有意义，但不能靠不断立刻自杀刷到世界无敌。**个人寿元是每世的第一限制，世界纪元独立延续**。时间和世界安全阀见 [10](10-TIME-EPOCH.md)，实物遗藏见 [11](11-LEGACY-ITEMS.md)。

## 一、三种离世方式
| 方式 | 条件 | 策略意义 |
|---|---|---|
| 寿终 | 到达个人寿限，未成功延寿/突破 | 这世修行成果成为永久传承 |
| 遇劫/冒险陨落 | 纪元斩杀线条件不足，或明示风险的探索失败 | 失败后记录事件原因、下一世可预先准备 |
| 主动轮回 | 达到有效成长门槛，玩家主动结束今生 | 舍弃继续冲关的机会，换取跨世积累 |

三种方式进入**同一个结算与选择遗泽流程**，但按本世真实贡献计分，不允许“意外死亡永久亏空”。

## 二、永久进展的两类账本
1. **轮回点 RP**：通用永久传承货币，用于四种少量关键升级。
2. **道痕/世录**：历史首次达成、寿龄纪录、纪元幸存、功法传承与世界线发现；控制后续解锁、剧情和一次性奖励。

跨世物件再分：
- **魂印遗泽**：有限槽位保留功法、异火和器魂的效应/记忆，可以跨纪元回溯。
- **世间遗藏**：**上一世实际留下的实体**，同一世界线下一世去寻回，不能直接凭空领回。存放、线索与唯一 ID 规则以 [11](11-LEGACY-ITEMS.md) 为准。

## 三、RP 奖励组成（示意，无实测数值）
`RP = 有效修行进展 + 寿龄/寿元突破纪录 + 纪元生存/阶段贡献 + 首次发现奖励 - 重复浅层路线递减项`

- **有效修行进展**以最高境界、实际修炼研究里程碑而非挂机年数裸值计算。只活得久、没有成长，不应刷出无限点数。
- **寿龄纪录**奖励首次活过年龄台阶（如 80、120、240 岁，数值仅示意）；同一个纪录重复达到不重复领首达点。
- **纪元生存**：遇到并跨越某一关口、为避劫采取准备、改变世界结果可得到积分；同一历史事件不能借读档/世界线重开无限刷首次奖励。
- **独特玩法探索**：首次尝试一条可行命格、独立构筑或找回首件遗藏，可以给一次性小额奖励；不依赖极低概率物品。
- **重复递减**只限制机械短轮回刷同一条浅层路线，不应压制真正在研究新流派或冲刺寿龄纪录的玩家。
- 主动提前轮回需要有合理进度门槛；结算面板提示“现在轮回”与“继续冲境界/等纪元”预期收益取舍。
- 失败也可有基础 RP，但必须与有效行动挂钩，不能只靠点一下“重开”循环获取。

## 四、四栏传承（少节点、不做巨大科技树）
| 栏目 | 持续收益 | 关键质变 |
|---|---|---|
| **修行记忆** | 基础修炼效率、减少低阶突破时间 | 自动完成已达成过的低级操作、拥有开局熟练功法 |
| **命途改写** | 更多出身/命格信息、选择空间 | 从两个开局倾向中挑选一种，或额外带一项轻量特征 |
| **遗泽铭刻** | 记住线索/遗泽效率 | 增加魂印槽位、提高寻找前世遗藏的效率 |
| **抗劫道痕** | 识别纪元危险、降低应劫准备成本 | 提前得知斩杀线的薄弱项、开启更多替代生路 |

**新增核心成长反馈：长寿纪念与遗物重逢。** 第一次活过一个寿龄大关、第一次找回前世实体，都应有专属记录和短叙事。

## 五、玩家要在轮回时做的实际选择
1. 是否主动转世，还是赌一把冲击突破/活过下一个世界斩杀线？
2. 本世哪份修炼心得化作魂印遗泽（初版一个槽位）？
3. 哪件**真实物品**已在世界中留存、下世准备去哪找？死亡时未准备的物品按 [11] 的遗留规则处理。
4. 下世选择默认的承世转生，还是进入特殊的纪元锚点回溯？**回溯将失去旧世界线的未带走实物**，须明确告知。

## 六、轮回结算信息
屏幕必须显示本世生卒世界年、年龄与寿限、最高境界、死亡原因、纪元关口表现、RP 各项来源、跨世遗泽选择、遗藏位置线索与下一世可达目标。玩家可以在确认前撤销主动轮回，不得误点后静默清除物品。

## 七、前 3–5 世爽点
- 第 1 世：第一次为突破延寿努力、预见或遭遇一道纪元关口、认识照世碑。
- 第 2 世：获得可感知传承、在世界里找回上一世一件物品，意识到世界并未重置。
- 第 3 世：依据提前得到的灾劫信息，选择不同生存路线；可能活得更久、通过上一世没跨过的危机。
- 第 4–5 世：命格 + 前世器灵/丹道/护界组合产生第一种真正的构筑分歧；解锁减少重复操作的能力。
**世数是体验参考，不是强制等待门槛；出色玩家可以少轮回获得同类能力。**

## 八、平衡验证
至少比较“60岁主动轮回 / 90岁寿尽 / 150岁突破延寿 / 纪元灾劫死亡”四类状态的时间成本与 RP，防止最优策略固定为不停重开或故意去斩杀线送死。长寿必须对获得更多世界事件、机缘和里程碑有独特回报，但不可使其成为唯一最优选择。
