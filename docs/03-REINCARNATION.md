# 03 · 轮回与永久成长系统（第一版规则提案）

> 设计目标：**每次轮回有所得，每几次轮回有质变**。不把一切折算为“修炼速度 ×1.1”，也不奖励没有意义的三秒刷轮回。

## 1. 两类跨世资产
1. **轮回点（RP）**：通过本世有效发展和大劫成绩得到，花费于四种永久传承，允许在结算前预览下一世变化。
2. **道痕/世录**：首次达到的境界、灾劫阶段、特殊事件等永久纪录；可作为解锁门槛和剧情线索，不必额外引入一个可消费的币种。

**前世遗泽** 是槽位制选择：每世结束时从本世达到门槛的物品/心得中指定少量保留，作为下世开局特征；它不是第三种刷取货币。

## 2. 轮回点结算：三个正向来源
- **成长分**：本世最高境界、修行研究里程碑、有效年份与关键事件的有限积分。
- **渡劫分**：击败阶段、坚持回合/保留灵脉的成绩；首次突破的奖励更高。
- **首次发现加成**：命格组合、隐藏异象、秘境成就与新纪录给予一次性点数（受总量上限约束）。
- 参考设计：`本世轮回点 = 基础成长分 + 渡劫分 + 首次成就分`，再考虑**已重复相同路线的收益递减**；系数与最终公式须离线模拟后再定。
- 减少利用漏洞：无实质提升的超短轮回只能获取很少/零点数；重复刷同一浅层路线存在边际递减，但**不能惩罚真正探索不同流派的玩家**。
- **不会因为付费/广告才给满额永久轮回点**。可选广告不改变首次里程碑记录。

## 3. 四条轮回传承（四个面板栏目，而非密集科技树）
| 传承 | 初级量变 | 关键质变节点（示例） | 主体价值 |
|---|---|---|---|
| 修行记忆 | 修炼效率、减少低阶突破耗时 | 自动完成已达成过的低阶突破；可从更高基础资源开局 | 免除枯燥 |
| 命途改写 | 提供额外命格候选、改善信息提示 | 开局从两种倾向中择一；保留一个非核心命格特质 | 每世不同 |
| 遗泽铭刻 | 扩大可继承的传承种类 | 解锁第 1/2 个遗泽槽、允许记忆功法的一个特性 | 有计划继承 |
| 抗劫道痕 | 提升初始护界/备劫研习效率 | 提前知道灾劫阶段弱点、使用特殊克制选项 | 反馈进步 |

**升级排序**：第一笔 RP 应能买到立刻可感知的效果；约在第 2–3 次轮回第一次体验“新选择/免操作”的质变。四栏面板可根据进度显示暂锁，不强迫玩家多处找分支。

## 4. 前世遗泽
- 每世通过一次明确选择带走最多 **1 件**非剧情限定“道途遗泽”（初始建议）；后期永久传承可开启第二槽。遗泽种类：功法印记/异火火种/法宝器魂/已知事件线索等。
- 遗泽是下世构筑起点，不是原物照搬：如“残剑剑魂”使剑诀研究提前、“青木火种”改善丹炉的可用路线。
- 不允许继承能直接跳过世界全部大劫的终极武器；同类遗泽有数量和稀有效果上限。
- 同一事件的首次标记永远保留在图鉴，但当前一世的临时物品/装备不会全部跨世保留。

## 5. 轮回结算 UX
面板必须清楚显示：本世历时、最高境界、渡劫到达阶段、所得 RP 的三项来源、首次发现、推荐但非强制的遗泽选择，以及 **下一世新解锁项**。
点击“开启下一世”前允许确认，存档在事务性提交后从新世开始，避免扣点成功但没得到能力。

## 6. 重复游玩驱动力
- **前 3 世**：更快修炼 + 第一次改变命格选择 + 遗泽带入下一世。
- **4–10 世**：两种截然不同功法/丹器选择；不同的抗劫薄弱点；新的突发事件和构筑路径。
- **更长期**：首通新世界阶段、道统、世界规则变体与新纪录。不能承诺无限手工剧情；靠“规则组合 + 目标变化 + 成长简化”扩展。
- 延迟解锁不得只靠轮回次数：需要同步检查真正达到过的境界、功法和大劫成绩，防止空刷解锁。

## 7. 平衡风险与模拟清单
- 一次 8–12 分钟的长轮回，是否有竞争力于连续三次 2 分钟短轮回？
- 永久加成多轮叠加是否指数失控，导致大劫变成无意义动画？
- 最优遗泽是否一枝独秀？普通开局是否仍有构筑机会？
- 最佳 RP 路径是否是重复低阶刷点？首次成就是否迫使玩家用攻略？
- 是否有一次失败无意义的情况？应保障合理参与有一部分跨世增长，但避免无限刷零成本失败。
