# 06 · 移动 UI 与视觉风格预案

> 目标：玩家随时知道 **我是谁、今年第几年、下一目标是什么、距离天劫还有多久**。界面不能变成十几层修仙科技树。

## 视觉语言
- **东方古典仙侠 + 清雅低饱和**：雾白、黛青、浅金、淡墨；少量朱红表示天劫危险，避免全屏金光和荧光按钮。
- 核心视觉资产：主角剪影/立绘、灵脉山川远景、境界变化、照世碑、三阶段天劫的差异化动画。
- UI 材质：半透明宣纸、细金线、木石纹理的轻点缀；字体清晰优先，不能为了国风牺牲小字可读性。
- 提供简洁“数值模式”：关闭绝大部分粒子/复杂动画后仍能高效游玩。
- 收藏/奇遇插图采用高质量少量独立资源，不在 MVP 中大量产出同质化 AI 人物头像。

## 9:16 竖屏布局（比例为提案）
```
┌─────────────────────────────┐
│ 第 N 世 · 第 43 / 100 年      │ ← 顶部常驻状态/灾劫倒计时
│ 金丹中期 · 修为+.../秒  [设置]│
├─────────────────────────────┤
│      山水/角色/异象主视觉     │
│      当前功法 / 修为进度      │ ← 视觉反馈与核心成长 35–45%
│      [突破]  [闭关]            │
├─────────────────────────────┤
│ 百年天劫：第 1 段准备  ...   │ ← 当前危机 & 下一目标
│ 本世机缘：残剑冢待处理  >     │
│ 目前瓶颈：缺灵材 20          │
├─────────────────────────────┤
│ [修行] [机缘] [备劫] [轮回]  │ ← 稳定四入口
└─────────────────────────────┘
```
- 顶部显示第几世/年份/当前境界和时间控制；不要滚动才能看到剩余年份。
- 主视觉与当前操作卡片优先，避免“满屏按钮+一大串红点”；按进度解锁子标签。
- 底部导航四个大按钮；打开子页后使用底部抽屉/一层详情，而不是连续弹窗。
- 功法/天赋/遗物提供一次清楚的推荐原因：改变哪项增长或天劫阶段。
- 本世首次事件可以弹出轻量选择卡，**年份自动暂停**，玩家选择后恢复；重复事件可快捷处理。

## 触控与输入
- 主要操作单手可达，默认触控热点约 44–48 逻辑像素及以上，再按设备屏幕密度调整。
- 支持刘海/圆角安全区和安卓系统手势区域；横屏不作为主设计目标。
- 长数字折行、动态字号、大字体模式/高对比度；帮助玩家区分倍率、产量与储量。
- 音效/震动可关闭，跳过重复突破动画；弱设备有低特效模式。
- 多段对话不强制播放、不阻碍保存；大劫阶段失败原因至少给一条可执行改进建议。

## 进度提示规则
- 仅提示与当前大劫瓶颈直接相关的 1–2 个目标，例“为灵潮阶段补充护灵丹”，而不是把所有未升级都变成红点。
- 资源不足明示缺口、来源和预计努力，不让玩家跨五级菜单寻找灵石。
- 每次轮回醒目标记“本世新发现 / 永久解锁 / 下世可用新选择”；重复提示可收起。
- 系统锁定时可展示解锁条件，但未解锁内容不反复骚扰玩家。
