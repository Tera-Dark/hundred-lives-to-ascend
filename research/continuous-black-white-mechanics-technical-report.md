## 00. 执行摘要：之前理解错在哪里

把《连续黑白》总结成「100年倒计时 → 升科技 → 被外星人打 → 轮回得点数」只看到了**灾劫外壳和结算**，没有看懂支撑玩家连续操作数小时的**人生经济发动机**。

更接近真实体验的闭环是：

  每日固定时间预算（睡眠 / 工作 / 研究 / 饮食通勤等生活开销）
  → 工作为一个具体岗位提供职业经验、等级和收入
  → 达到前置条件逐级晋升、打开工资更高的职位/行业
  → 收入与投资积累购买饮食/住所/交通/雇佣等生活增益
  → 基础精力、工作经验、研究经验、可用于研究的时间获得提升
  → 研究「工作收入/投资/效率/精力/科技/防御」等增强经济或推进防御
  → 更快爬升本世最高职业/研究等级
  → 历史最高等级等资产影响下世经验效率、带来成长差
  → 轮回后可更快进入下一阶段、尝试不同时间配置与解锁分支。

职业不是玄修/丹修那样**开局按一个按钮选人生流派**，而是本世能够**持续升级、转岗与解锁更高级岗位的职业阶梯**。真正的策略是：一生的时间与钱在什么时候投入“挣钱、改善生活、研究、备战、主动结算”。

## 02. 职业体系：职业不是标签，是“岗位阶梯”

### 2.1 已有证据能确认什么

开发者搬运的开荒攻略提供了以下信息：
- 有**运输、科研、AI、娱乐圈、星空舰队**至少五个行业。攻略说不考虑情商加成时，收入表现大致是 **星空舰队 > 娱乐圈 > AI > 科研 > 运输**。[A]
- AI路线可以由较低职位如 **AI测试员**逐步提升到 **星火董事长**；娱乐圈可追求 **星空巨星**，星空舰队可追求 **星空指挥官**。[B]
- 前置职位本身也需要升级。攻略建议将所选行业的多个前置岗位练到 **400–500级**，达到高阶职业会更加顺畅；顶端目标还建议历史300–500级。[B]
- 部分行业/职业需满足特定「穿越者」等级，例如攻略中的 **高曼琳/王文婷40级**可解锁关联付费职业（具体对应关系和当前版本条件应以客户端为准）。[A/B]
- “职业到第几级解锁下一职务”的**完整岗位列表、精确门槛、工资公式、晋升时是否保留旧岗经验**，公开可检索资料并没有覆盖完，**不能擅自造一张完整职业表**。

### 2.2 这一套岗位阶梯为何有趣（机制推导，[C]）

每个岗位充当局内可不断完成的**近程目标**：
1. 工作时间积累当前岗位经验→等级上涨→眼前反馈；
2. 达成前置岗位/行业条件→解锁新岗位→工资或经验速度产生阶跃；
3. 新工资使当前档次生活条件/投资研究可负担；
4. 生活效率提高后**回头更快练旧职业、上新职业**；
5. 每项工作都有历史最高纪录，**即便这世只推进一部分，也可能留给下一世效率上的收益**。

这比“玄修：修为每年+40；丹修：材料消费更省”密得多：玩家有**正在练的职位、下一职务门槛、下一个生活升级、研究短目标和下一轮历史纪录**，多个短期目标在同一计时器上接力。

### 2.3 对职业数值模型的可实现抽象（推导，不是《连续黑白》真实源码）

- Job = {industryId, jobId, level, exp, requiredPreviousJobs, incomeRate, incomeModifiers}
- Player = {dailyWorkMinutes, dailyResearchMinutes, dailyRestMinutes, assets, baseEnergy, energyMultiplier}
- History = {bestJobLevels[jobId], bestResearchLevels[researchId]}
- 每段时间按当前策略：工作经验 ~ 工作时间 × 精力 × 工作经验倍率 × 历史最高修正；工作现金流 ~ 工作时间 × 岗位工资 × 工作收入倍率。
- **所有精确函数、取整、相乘/相加乘区、岗位晋升时点均为待实测项。**

## 03. 生活与精力：收入不是终点，而是增长效率的投入品

官方明确存在：
- **饮食**：不同饭菜方案，有现金支出、少量吃饭时间消耗；玩家攻略举例一顿饭要15分钟；
- **住宅**：消费换居住增益和相关效率；
- **交通**：车型影响通勤时间，攻略举例汽车30分钟与单车90分钟；
- **雇佣**：研究助理、秘书、清洁工、全职保姆等改善研究/生活时间占用与效率；
- 后期甚至会优化“每小时是否值得留给睡眠”，出现睡眠0、工作23小时15分钟的极端阶段性策略。[B]

官方Q&A的**精力作用是提高工作和研究等级成长效率**。在有钱以后优先购买生活条件，让更多时间与更高效率转为研究进展。因此现金变成了“生产率投资品”，不会止于数字余额。[A]

### 3.1 玩家为何会主动调整生活方案

“生活越豪华越好”不是无脑定律：昂贵的选择持续扣现金、也可能占用时间，如果净收入为负会拖慢科研与扩建。玩家攻略反复提醒**要保持净收入不大幅为负**。前期往往是追求收入/生活，50岁以后转向研究/防御，而不是从入世到死亡只按一次修炼按钮。[B]

## 04. 六维属性与经验乘区（基于官方2026-04攻略）

| 属性 | 官方公开规则描述（高于100的部分才产生六维加成） |
|---|---|
| 心态 | 每点 +0.5% 精力（注意是否作用于基础精力的精确细节需实测） |
| 健康 | 每点 +0.01 基础精力 |
| 智商 | 每点 +1% 研究经验 |
| 情商 | 每点 +1% 工作经验及+1%工作收入 |
| 创意 | 每点减少0.1%研究所需经验，减免至多99% |
| 运气 | 每点+1万初始资金，+0.1%掉落率，上限100% |

官方还明确：基础精力初始1不计在相关加成描述里，基础精力额外每0.01可能增加约1%工作与研究经验；**精力、研究、工作经验等加成处于不同层次的乘法关系**，而不是所有属性简单相加。[A]

**工程理解**：这里有至少3种不同数值作用面——经验所得速率、升级所需经验成本、任务花费时间，以及收入速率，带来了跨乘区优化。例如“增加研究经验”与“降低升级所需经验”都会提速，但适用范围/收益函数不同。[C] **不得直接把此表当最终数值公式**：官方文字还有歧义，实际取整/封顶及版本变更需要客户端量测。

## 05. 人生时间分配：局内真正的稀缺资源

官方与攻略记录了至少三类典型政策：
| 阶段 | 睡眠 | 工作 | 研究 | 意图 |
|---|---|---|---|---|
| 最早期 | 8小时 | 8小时 | 其余可用时间 | 同时起步挣钱与研究 |
| 资金积累/“黑奴”打法 | 甚至0 | 极高，可达23:15 | 接近0 | 用时间换现金和投资本金 |
| 富裕后的科研期 | 约8小时 | 0~6小时 | 大量剩余时间 | 利用生活加成迅速堆研究与历史纪录 |

“23:15”是发布者搬运玩家打法，不应理解为官方推荐的唯一最优。它借助**生活活动分钟成本**使时间分配可微调：如何减少通勤、饭食占用，何时提神，在同一个寿龄上限内累积更多等级。[B]

### 5.1 可推导的动态战略决策（不是客户端精确算法）

在早期，工作额外1小时产生收入；收入买生活项，提升未来几十年研究速率。晚期同一小时若再用于工作，机会成本可能高过研究。因此**最优政策随寿龄、历史继承、当前储蓄、研究瓶颈变化**，产生玩家可体会的中途“换挡”。

核心难题是“**何时结束赚钱期**”，而不只是“今天该选哪种buff”。官方玩家攻略称只要买得起最好的生活项目就可结束资金期，并指出投资收益只与存款有关，[B]因此会发生“存款→投资收入→生活升级→再增长”的资本加速循环。

## 06. 局内研究与工作的双向正反馈

可直接查证的研究短目标包括：
- 研究**概论、活力、投资、学习算法**，高等级也会影响往后升级效率；
- 根据行业研究**演员自我修养、星空舰队导论**等专属方向；
- 研究提升**精力、研究经验、工作经验、工作收入、投资相关收益**；
- 发展至某些研究等级后解锁进一步研究、雇佣与近地防御能力。
这些形成了至少三股资金/经验关系：

1. **职业收入 → 购买生活增益 → 工作/研究升级更快**；
2. **研究投资与工作收入 → 现金增长更快 → 生活增益更早买到**；
3. **研究精力/工作经验/算法 → 岗位等级更快 → 更高工资与永久历史纪录**。

可简化为：

  Cash[t+1] = Cash[t] + JobIncome(t) + InvestmentIncome(Cash[t]) - LifestyleCosts(t)
  JobExp[t+1] = JobExp[t] + WorkTime(t) * WorkEfficiency(energy, stats, research, history)
  ResearchExp[t+1] = ResearchExp[t] + ResearchTime(t) * ResearchEfficiency(energy, stats, life, history)

**以上为研究者推导的伪数学模型，不能引用为游戏官方公式。** “研究所需经验”可能还受创意等成本减免影响。多个倍率叠乘会让中期从缓慢进展转换为加速成长，但也容易造成收益爆炸或研发一个职业就统治所有策略。

## 07. 轮回不是只给一种“轮回点”

官方Q&A给出了至少四类按来源/用途区分的永久进度资源：
| 资源 | 获取方式 | 用途 | 对局内经济的反馈 |
|---|---|---|---|
| **记忆因子** | 工作/研究突破最高历史等级 | 升级“时间弹性” | 延伸每世成长与基础属性能力 |
| **时间结晶** | 使用时间加速/轮回核算 | 升级“轮回记忆”部分节点 | 强化生活、研究等 |
| **高维核心** | 满足记忆节点前置后，时间加速转换 | 轮回记忆中战斗/星空节点等 | 解锁中高阶机制 |
| **轮回勋章** | 本世完成任务结算 | 积分商店兑换 | 鼓励不完全相同的单世目标 |

加上**历史最高工作/科研等级经验加成**，还构成一种不需要先花货币的“隐性局外存量”。官方攻略明确推荐**早期只比上一世有无提升50或100级，不强求一世突破200级**。[A]

**主动/被动重开**：星球失守触发被动轮回；研究到“超时空轮回”才可自行发起主动轮回。[A]

### 7.1 值得研究的“轮回速度 vs 单世深度”
官方明确表示速刷轮回可以加快部分时间记忆/勋章收益，却会损失持续战斗的收益。因此玩家会在：
- 快速活几轮，重置积累基础效率；
- 放慢一世、发展更深远战斗/科技；
之间选择。玩家已有资产决定哪个方案此时更值。[A]

### 7.2 重要Q&A细节
- “时间跃迁”可跳到**当前/上世40岁**的记录，用于略过早期重复赚钱的机械操作（具体快照规则未实测）；
- 消耗加速时间可以转为时间结晶、高维核心，部分轮回科技改变转换效率；
- 轮回记忆不是一个无脑倍率列表，里面还有生活、战斗、星空多类分组和前置。
**其弱点是分组/币种过多，后期成本与关键路径不易理解。**

## 08. 战斗与长期篇章：为什么赚钱最后不是为了继续赚钱

### 8.1 最初阶段
前期大量时间被「岗位/收入/生活/科研」经济循环占据。约40岁首次出现低机动的机制怪，玩家可以开始建造地表防御；约80岁隐身敌人需要轨道雷达等机制专属应对。**局内经济不是独立小游戏，最后必须服务对外星威胁的能力。**[A]

### 8.2 后期目标转换
官方Q&A记录了研究轨道建筑、宇宙港、地表词条、星舰建造、虫洞、副本、远征、深空矿物与所谓“神圣时间线”中的建筑、星门、星系等内容。[A]
- 在普通模式约75岁后出现虫洞内容；
- 通过近地轨道宇宙港满足舰船空间，旗舰等高级舰种有更深层前置；
- 神圣时间线会从此前分支获取资源、星舰等，再投入更大的文明系统。
这些说明**经济模型阶段性改换最终消费目标**：早期钱买效率，中期等级开战斗能力，后期科技/掉落材料支撑更宏大的星际目标。

**注意**：可证实“存在这些模块和某些门槛”，不能断言当前各模块均易达成或全功能无门槛。

## 09. 结构层面的真正游戏乐趣

**乐趣1：嵌套的短目标链。** 当前岗位下一级→高工资岗位→下一生活项→更快研究→新研究技能→提高历届纪录；玩家不会只剩一根修为进度条。

**乐趣2：时间分配是持续决策。** 同样寿限内，把每天1小时从工作转去科研，会改变当前与未来的总收益；玩家会根据职业/存款/精力/下一次灾劫不断调整。

**乐趣3：增长系统互相反哺。** 钱花掉不是损失，而是投资提高未来所有行为效率。研究除了推动剧情，也能提升赚现金的生产率，形成增量爆发。

**乐趣4：阶段性策略翻转。** 一段时间只挣钱，之后突然切为全天科研；下一世因历史最高等级加速，可以更早退出赚钱期。**每次轮回不只是重复原来4个按钮，生活方式本身会变化。**

**乐趣5：外部威胁赋予机会成本。** 专注生活升级可能错过备战窗口，提早科研可能缺钱，过早轮回拿不到战斗奖励；改变政策必须看剩余时间。

**乐趣6：自动化后可直接跳过熟练前戏。** 随着历史最高和时间跃迁，前期原本有手操价值的重复工作不该永远要求玩家再做。

以上是**结合可查资料的设计解释[C]**，不等于开发团队公开的正式产品设计声明。

## 10. 其真实弱点：哪些绝对不该照搬

对照 [TapTap评价页面](https://www.taptap.cn/app/834077/review) 2026年6–9月多条评论：
- **付费职业或指定穿越者挡住内容**：玩家抱怨缺少角色即无法解锁更高职业/研究/星舰；另有官方攻略提到特定穿越者40级解锁某些职业。这些是玩家体验中的严重可达性风险，不可学习。
- **数十层前置链与数千级科技**：部分玩家反映升级过程中必须一层层查询依赖、频繁微调提神；造成“卡解锁”的痛苦。
- **倍率和大量货币堆叠**：乘区难理解，某一条可付费乘区可能远胜所有非付费组合，反复轮回却无法打开新玩法。
- **生活微操可能被极端最优打法劫持**：0睡眠/23:15工作是玩家发现的效率策略，但会让休闲玩家必须重复调整精确分钟，否则感到明显落后。
- **攻略依赖**：数百级前置与战斗科技门槛缺少清晰的下一目标，简单 UI 并不意味着系统清楚。
- **评价分化**：一些玩家肯定前期增长、解锁新阶段的满足感；另一些玩家对付费职业、长串科技前置和后期枯燥非常不满。评论是个体意见，不能直接推算所有玩家的真实分布。

对于《百世劫录》，应学习**职业成长阶梯+生活改善反哺+时间分配切换+历届纪录带入**，而不是照搬**数千级前置、付费职业、强制分钟微操、层层货币与高阶生存墙**。

## 11. 我们MVP-0为什么显得单调（针对性诊断，不是修改指令）

目前《百世劫录》原型的主要局内增长是：
  选玄修/丹修 → 被动修为及灵石年产 → 第18/34年做一次资源选择 → 第39年命关 → 第60年生存判定 → 轮回。

它有两个**解题方案**，却几乎没有长期可重复的**经营行为**。具体表现：
1. **缺“中间生产职业”**：玩家不能靠一连串工作/修行职务逐级获得更好的收入与技能；只有修为被动上涨；
2. **收入缺有效消费出口**：钱主要付固定动作，不会常态提升下一段修炼的基础效率；
3. **没有日常精力/效率层**：除少数事件外，玩家很少主动重新分配有限寿元下的精力与时间；
4. **职业没有纵向晋升梯**：玄修/丹修是解劫横向流派，不是“入门职位→中级职位→高级职位”的进程；
5. **玩家没有可反复经营的阶段策略**：难形成“前20年赚钱、30年后转精修”的自发节奏；
6. **轮回只缩短等待、没有重写经营节奏**：有RP时更快筑基，却未必要求采用新的资源/时间策略。

最重要的差异是：**横向流派与纵向人生职业应是两个不同维度**。《连续黑白》的岗位阶梯负责持续成长行为，行业选择负责收入/研究协同；《百世劫录》当前主修只实现了横向过劫分化，纵向经营发动机尚不存在。

## 12. 可迁移的设计原则：用户审查前仅提出研究假说

**暂不确定游戏修改方案**。以下是理解原作机制后提出的候选“抽象映射”，供用户检验我是否理解正确：
- 职业晋升层：坊市学徒→采药客→炼材师→炼丹供奉→宗门执事等**生活职业阶梯**（举例非最终职业设定），与已有玄修/丹修主修道途并行而不互斥；
- 日常分配层：打工/修炼/历练/休养，寿元或者精力预算固定，提升某项必然减少另一项时间；
- 财富消费层：洞府、灵食、聚灵环境、雇佣帮手等变成有价且不断改善**修为、精力、历练效率**的增量投资，不能只是买一件装备；
- 持久性层：本世最高职业、修为纪录、生活成就形成“下世前几步更快”的永久经验资本；
- 目标层：修仙突破、个人命关、纪元事件要求玩家在赚钱、修炼与备劫之间作取舍；
- 自动化：完成某一职业阶梯后允许一键复现经过验证的旧阶段，降低反复重做的负担；
- 五流派作为“对同一个经济体系的不同利用手法”，而不是五条独立生产树。

**这些映射只是讨论题，不是正式 PRD，不代表已获用户批准。** 必须首先确认《连续黑白》原职业完整解锁链、现金/生活/精力反馈环里最有乐趣的部分；之后才重构我们自己的数值与玩法。

## 14. 核心判断与用户审核点

我认为玩家指出的问题成立：我们的试玩版此前把关注点放在**纪元/寿命/历史不重播/两种生存解法**，却漏掉了原参照游戏最值得借鉴的 **“每个游戏年都可以持续优化的工作/研究/生活三角构筑”**。

用户审核时，请重点判断三点是否符合你的实际游玩认识：
1. **职业是逐级晋升的持续成长链，而不是只选一个带特殊技能的职业。**
2. **收入要通过生活改善转化为全局效率，形成持续反馈；生活还要与精力/一天有限时间互相牵制。**
3. **轮回的爽点不仅是永久点数，更是保留历史最高等级和科技经验加成，令下一世前期成长速度、阶段切换时机发生改变。**

**在得到审核反馈之前：只做研究，不更改《百世劫录》现有模拟经济、职业系统或游戏数值。**
